# L066练习与答案

1. **[基础·概念辨析]** 完成下面这项任务后，有同学的解释出现“方向画反”。任务：磁体周围放多枚小磁针并标N极方向。请指出应补充或改正的关键条件。

   **答案**：先按“小磁针N极受力方向定义场方向”圈定研究对象和条件，再改正该判断；不能只写错误名称。
2. **[基础·读数/计算]** 条形磁体外部磁感线方向。

   **答案**：从N极到S极。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 围绕“条形磁体场线图”，标出研究对象、关键方向或变量，并用图得出“小磁针N极受力方向定义场方向”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·证据与实验]** 完成“磁体周围放多枚小磁针并标N极方向”时，写出要比较的对象、只改变或重点比较的条件，以及应记录的现象。

   **答案**：围绕“小磁针N极受力方向定义场方向”完成一次清楚比较：先定对象和条件，再记录能支持或否定“磁场对放入其中的磁体有力作用”的现象；一次操作不能外推成普遍定律。
5. **[提升·解释论证]** 把下面的核心问题改成可检验的问题，并写出需要取得的证据：磁体没有接触，为什么能推动小磁针？

   **答案**：先圈定对象和条件，再用“小磁针N极受力方向定义场方向”连接证据与结论。如果出现“把磁感线当真实线”，订正这个判断步骤后，再用一道同类题确认。
