# L066练习与答案

1. **概念判断**：用自己的话解释“磁场对放入其中的磁体有力作用”。  
   **答案**：必须同时说出物理对象和关系：小磁针N极受力方向定义场方向。只重复标题不算完成。
2. **条件辨认**：不用公式，只用“小磁针N极受力方向定义场方向”判断并说明条件。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C3方向画反”。
3. **图示应用**：请画一张“条形磁体场线图”，用图解释“小磁针N极受力方向定义场方向”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：条形磁体外部磁感线方向。  
   **答案**：从N极到S极。关键模型：小磁针N极受力方向定义场方向。
5. **情境与错因侦探**：同学完成“磁体周围放多枚小磁针并标N极方向”后出现“C1把磁感线当真实线”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C1把磁感线当真实线**。先检查与“小磁针N极受力方向定义场方向”直接相关的对象和条件，再决定重画图、重读数或重算。
