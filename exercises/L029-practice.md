# L029｜弹力与弹簧测力计｜10分钟练习

1. **[基础·北京题型：概念辨析]** 在“检查零点、量程、分度值，体验并测量1 N与书的重力”中，有同学出现了“超过量程仍使用”。这个结论可靠吗？

   **答案**：不可靠。应先按“在限度内形变量反映力大小”核对研究对象和条件。
2. **[基础·北京题型：读数/计算]** 测力计每大格1 N分5小格，指3小格。

   **答案**：0.6 N。关键条件：对象、过程和单位必须配对。
3. **[典型·北京题型：读图作图]** 围绕“测力计读数图”，标出研究对象、关键方向或变量，并用图得出“在限度内形变量反映力大小”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·北京题型：实验探究]** 要完成“检查零点、量程、分度值，体验并测量1 N与书的重力”，写出本次只改变或重点比较的量，以及判断结论所需的证据。

   **答案**：围绕“在限度内形变量反映力大小”只改变一个关键因素，其他条件保持一致；至少取得可比较的数据或清楚现象，不能由一次偶然结果下结论。
5. **[提升·北京题型：解释/论证]** 把“拉得越长，弹簧的拉力一定越大吗？”改成可检验的问题，并写出需要取得的证据。

   **答案**：先圈定对象和条件，再用“在限度内形变量反映力大小”连接证据与结论。如果出现“未校零”，订正这个判断步骤后，再用一道同类题确认。
