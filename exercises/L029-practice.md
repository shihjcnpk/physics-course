# L029练习与答案

1. **[基础·概念辨析]** 完成下面这项任务后，有同学的解释出现“超过量程仍使用”。任务：检查零点、量程、分度值，体验并测量1 N与书的重力。请指出应补充或改正的关键条件。

   **答案**：先按“在限度内形变量反映力大小”圈定研究对象和条件，再改正该判断；不能只写错误名称。
2. **[基础·读数/计算]** 测力计每大格1 N分5小格，指3小格。

   **答案**：0.6 N。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 围绕“测力计读数图”，标出研究对象、关键方向或变量，并用图得出“在限度内形变量反映力大小”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·证据与实验]** 本课核心实验怎样保证结论可信？写出主动改变的量、观察测量的量和关键控制条件。

   **答案**：主动改变：测量类，无自变量；观察测量：力的示数；关键控制：校零、量程、分度值和受力方向；证据记录：原始示数、单位及是否超量程。
5. **[提升·解释论证]** 把下面的核心问题改成可检验的问题，并写出需要取得的证据：拉得越长，弹簧的拉力一定越大吗？

   **答案**：先圈定对象和条件，再用“在限度内形变量反映力大小”连接证据与结论。如果出现“未校零”，订正这个判断步骤后，再用一道同类题确认。
