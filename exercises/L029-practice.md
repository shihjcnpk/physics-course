# L029练习与答案

1. **概念判断**：用自己的话解释“弹性形变产生弹力且有弹性限度”。  
   **答案**：必须同时说出物理对象和关系：在限度内形变量反映力大小。只重复标题不算完成。
2. **条件辨认**：不用公式，只用“在限度内形变量反映力大小”判断并说明条件。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C7超过量程仍使用”。
3. **图示应用**：请画一张“测力计读数图”，用图解释“在限度内形变量反映力大小”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：测力计每大格1 N分5小格，指3小格。  
   **答案**：0.6 N。关键模型：在限度内形变量反映力大小。
5. **情境与错因侦探**：同学完成“检查零点、量程、分度值，体验并测量1 N与书的重力”后出现“C9未校零”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C9未校零**。先检查与“在限度内形变量反映力大小”直接相关的对象和条件，再决定重画图、重读数或重算。
