# L070｜信息、能源与可持续未来｜10分钟练习

1. **[基础·北京题型：概念辨析]** 在“为“节能小屋”在太阳能、风能和市电间做证据化选择”中，有同学出现了“可再生等同无影响”。这个结论可靠吗？

   **答案**：不可靠。应先按“需求—证据—约束—方案—评价”核对研究对象和条件。
2. **[基础·北京题型：读数/计算]** 波速3×10^8 m/s、频率10^8 Hz，波长。

   **答案**：3 m；方案还需评价稳定性与环境影响。关键条件：对象、过程和单位必须配对。
3. **[典型·北京题型：读图作图]** 围绕“方案评价矩阵”，标出研究对象、关键方向或变量，并用图得出“需求—证据—约束—方案—评价”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·北京题型：实验探究]** 要完成“为“节能小屋”在太阳能、风能和市电间做证据化选择”，写出本次只改变或重点比较的量，以及判断结论所需的证据。

   **答案**：围绕“需求—证据—约束—方案—评价”只改变一个关键因素，其他条件保持一致；至少取得可比较的数据或清楚现象，不能由一次偶然结果下结论。
5. **[提升·北京题型：解释/论证]** 把“技术选择怎样同时看物理可行性与社会影响？”改成可检验的问题，并写出需要取得的证据。

   **答案**：先圈定对象和条件，再用“需求—证据—约束—方案—评价”连接证据与结论。如果出现“只看单一指标”，订正这个判断步骤后，再用一道同类题确认。
