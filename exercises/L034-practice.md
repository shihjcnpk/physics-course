# L034练习与答案

1. **概念判断**：用自己的话解释“压强表示单位面积承受的压力”。  
   **答案**：必须同时说出物理对象和关系：压力与受力面积共同决定效果。只重复标题不算完成。
2. **条件辨认**：写出p=F/S中各量对应的对象，并说一个不能直接使用它的情形。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C7只看压力”。
3. **图示应用**：请画一张“压力面积对比图”，用图解释“压力与受力面积共同决定效果”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：600 N站在0.04 m²地面，压强。  
   **答案**：15000 Pa。关键模型：压力与受力面积共同决定效果。
5. **情境与错因侦探**：同学完成“同一块橡皮分别平放和竖放在海绵上”后出现“C5面积换算错”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C5面积换算错**。先检查与“压力与受力面积共同决定效果”直接相关的对象和条件，再决定重画图、重读数或重算。
