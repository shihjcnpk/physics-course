# L038｜浮力：浸在流体里的向上作用｜10分钟练习

1. **[基础·北京题型：概念辨析]** 在“先在空气再浸水读取测力计，比较示数”中，有同学出现了“漏竖直向上”。这个结论可靠吗？

   **答案**：不可靠。应先按“弹簧测力计示数差测浮力”核对研究对象和条件。
2. **[基础·北京题型：读数/计算]** 空气5 N、水中3 N，浮力。

   **答案**：2 N。关键条件：对象、过程和单位必须配对。
3. **[典型·北京题型：读图作图]** 围绕“称重法受力图”，标出研究对象、关键方向或变量，并用图得出“弹簧测力计示数差测浮力”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·北京题型：实验探究]** 要完成“先在空气再浸水读取测力计，比较示数”，写出本次只改变或重点比较的量，以及判断结论所需的证据。

   **答案**：围绕“弹簧测力计示数差测浮力”只改变一个关键因素，其他条件保持一致；至少取得可比较的数据或清楚现象，不能由一次偶然结果下结论。
5. **[提升·北京题型：解释/论证]** 把“铁块在水里为什么“变轻”？”改成可检验的问题，并写出需要取得的证据。

   **答案**：先圈定对象和条件，再用“弹簧测力计示数差测浮力”连接证据与结论。如果出现“把示数当浮力”，订正这个判断步骤后，再用一道同类题确认。
