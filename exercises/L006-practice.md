# L006｜声音从哪里来、怎样传过去｜10分钟练习

1. **[基础·北京题型：概念辨析]** 【2022北京中考第3题同型】琴弦正在发声。下列说法正确的是：A.琴弦不振动 B.声音可在真空传播 C.可凭音色区分乐器 D.音调相同则响度必相同。

   **答案**：C。声音由振动产生，不能在真空传播；音调与响度是不同特性。
2. **[基础·北京题型：读数/计算]** 太空舱外爆炸能否直接听见。

   **答案**：不能；真空不能传声。关键条件：对象、过程和单位必须配对。
3. **[典型·北京题型：读图作图]** 围绕“振动传播链图”，标出研究对象、关键方向或变量，并用图得出“声源振动→介质传递→耳接收”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·北京题型：实验探究]** 要完成“摸喉咙、拨橡皮筋，再用纸杯电话比较”，写出本次只改变或重点比较的量，以及判断结论所需的证据。

   **答案**：围绕“声源振动→介质传递→耳接收”只改变一个关键因素，其他条件保持一致；至少取得可比较的数据或清楚现象，不能由一次偶然结果下结论。
5. **[提升·北京题型：解释/论证]** 罩内闹钟随抽气逐渐变小，为什么不能据此直接说‘抽到真空后仍能听见’？

   **答案**：装置难达到绝对真空且罩体也可能传声。可靠结论来自声音随空气减少而减弱，再外推真空不能传声。
