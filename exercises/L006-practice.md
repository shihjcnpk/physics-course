# L006练习与答案

1. **概念判断**：用自己的话解释“声音由振动产生并需介质传播”。  
   **答案**：必须同时说出物理对象和关系：声源振动→介质传递→耳接收。只重复标题不算完成。
2. **条件辨认**：不用公式，只用“声源振动→介质传递→耳接收”判断并说明条件。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C2漏介质”。
3. **图示应用**：请画一张“振动传播链图”，用图解释“声源振动→介质传递→耳接收”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：太空舱外爆炸能否直接听见。  
   **答案**：不能；真空不能传声。关键模型：声源振动→介质传递→耳接收。
5. **情境与错因侦探**：同学完成“摸喉咙、拨橡皮筋，再用纸杯电话比较”后出现“C1把声音当物质”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C1把声音当物质**。先检查与“声源振动→介质传递→耳接收”直接相关的对象和条件，再决定重画图、重读数或重算。
