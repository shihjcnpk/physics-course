# L051｜能量守恒、效率与方向｜10分钟练习

1. **[基础·北京题型：概念辨析]** 在“给手机充电能量流贴标签并找散失”中，有同学忽略了“C7效率超过100%”。这个结论可靠吗？

   **答案**：不可靠。应先按“输入能量=有效+散失”核对研究对象和条件。
2. **[基础·北京题型：读数/计算]** 输入100 J，有用70 J，散失多少。

   **答案**：30 J；守恒不等于都能再利用。关键条件：对象、过程和单位必须配对。
3. **[典型·北京题型：读图作图]** 围绕“能量流桑基简图”，标出研究对象、关键方向或变量，并用图得出“输入能量=有效+散失”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·北京题型：实验探究]** 要完成“给手机充电能量流贴标签并找散失”，写出本次只改变或重点比较的量，以及判断结论所需的证据。

   **答案**：围绕“输入能量=有效+散失”只改变一个关键因素，其他条件保持一致；至少取得可比较的数据或清楚现象，不能由一次偶然结果下结论。
5. **[提升·北京题型：解释/论证]** 把“能量守恒，永动机为什么仍不可能？”改成可检验的问题，并写出需要取得的证据。

   **答案**：先圈定对象和条件，再用“输入能量=有效+散失”连接证据与结论。若出现“C1守恒等同不变形式”，归入 **C1守恒等同不变形式** 并只修对应步骤。
