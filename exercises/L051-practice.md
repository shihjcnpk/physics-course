# L051练习与答案

1. **概念判断**：用自己的话解释“能量总量守恒但转化有方向且品质会分散”。  
   **答案**：必须同时说出物理对象和关系：输入能量=有效+散失。只重复标题不算完成。
2. **条件辨认**：写出E入=E有+E散中各量对应的对象，并说一个不能直接使用它的情形。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C7效率超过100%”。
3. **图示应用**：请画一张“能量流桑基简图”，用图解释“输入能量=有效+散失”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：输入100 J，有用70 J，散失多少。  
   **答案**：30 J；守恒不等于都能再利用。关键模型：输入能量=有效+散失。
5. **情境与错因侦探**：同学完成“给手机充电能量流贴标签并找散失”后出现“C1守恒等同不变形式”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C1守恒等同不变形式**。先检查与“输入能量=有效+散失”直接相关的对象和条件，再决定重画图、重读数或重算。
