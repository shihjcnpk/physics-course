# L012练习与答案

1. **[基础·概念辨析]** 水沸腾后温度稳定在98 ℃。继续加热时，水是否还吸热？98 ℃说明什么？

   **答案**：仍吸热，能量用于汽化；98 ℃是当时条件下的沸点，不能强改成100 ℃。
2. **[基础·读数/计算]** 水沸腾后读数保持98℃说明什么。

   **答案**：当地条件下沸点约98℃，继续吸热用于汽化。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 画“沸腾装置与曲线图”：先画正在加热的水，再标出比较沸腾前和沸腾时的温度，最后在图旁写出看到的结果。

   **答案**：图中对象：正在加热的水；比较或变化：比较沸腾前和沸腾时的温度；结果：沸腾时气泡剧烈形成，温度近似不变；结论：液体达到沸点并继续吸热才沸腾；沸腾时温度保持不变。
4. **[典型·证据与实验]** 本课核心实验怎样保证结论可信？写出主动改变的量、观察测量的量和关键控制条件。

   **答案**：主动改变：加热时间；观察测量：水温和气泡特征；关键控制：水量、容器、热源与温度计位置；证据记录：多组温度—时间数据和沸腾前后现象。
5. **[提升·解释论证]** 实验只记录一次沸腾温度就下结论可靠吗？写出至少两项改进。

   **答案**：不可靠。应等水充分沸腾后连续多次读数，并重复实验；同时规范温度计位置、读数视线和加热条件。
