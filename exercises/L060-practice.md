# L060练习与答案

1. **[基础·概念辨析]** 完成下面这项任务后，有同学的解释出现“跨对象拼数据”。任务：给电路某电阻框边界，标其电压电流再计算。请指出应补充或改正的关键条件。

   **答案**：先按“圈定研究对象再配U、I、R”圈定研究对象和条件，再改正该判断；不能只写错误名称。
2. **[基础·读数/计算]** 0.5 A通过12 Ω电阻，电压。

   **答案**：6 V。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 围绕“局部电路框图”，标出研究对象、关键方向或变量，并用图得出“圈定研究对象再配U、I、R”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·证据与实验]** 把例题信息整理成“对象—条件—关系—结论”四格，不增加题目没有给出的条件。

   **答案**：对象和条件必须来自题目；关系使用“圈定研究对象再配U、I、R”；最后用单位或物理意义检查结论。
5. **[提升·解释论证]** 把下面的核心问题改成可检验的问题，并写出需要取得的证据：电路题怎样先找对象再列式？

   **答案**：先圈定对象和条件，再用“圈定研究对象再配U、I、R”连接证据与结论。如果出现“对象边界错”，订正这个判断步骤后，再用一道同类题确认。
