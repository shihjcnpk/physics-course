# L060练习与答案

1. **概念判断**：用自己的话解释“欧姆定律只对同一段电路同一状态配对”。  
   **答案**：必须同时说出物理对象和关系：圈定研究对象再配U、I、R。只重复标题不算完成。
2. **条件辨认**：写出U=IR中各量对应的对象，并说一个不能直接使用它的情形。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C7跨对象拼数据”。
3. **图示应用**：请画一张“局部电路框图”，用图解释“圈定研究对象再配U、I、R”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：0.5 A通过12 Ω电阻，电压。  
   **答案**：6 V。关键模型：圈定研究对象再配U、I、R。
5. **情境与错因侦探**：同学完成“给电路某电阻框边界，标其电压电流再计算”后出现“C2对象边界错”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C2对象边界错**。先检查与“圈定研究对象再配U、I、R”直接相关的对象和条件，再决定重画图、重读数或重算。
