# L014｜升华、凝华与水循环｜10分钟练习

1. **[基础·北京题型：概念辨析]** 冷冻室内壁的霜不是液态水冻成的。写出形成霜的初态、末态和名称。

   **答案**：水蒸气由气态直接变为固态冰晶，属于凝华。
2. **[基础·北京题型：读数/计算]** 窗上冰花通常形成在哪一侧。

   **答案**：室内侧；水蒸气遇冷凝华。关键条件：对象、过程和单位必须配对。
3. **[典型·北京题型：读图作图]** 围绕“水循环箭头图”，标出研究对象、关键方向或变量，并用图得出“固↔气与水循环状态链”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·北京题型：实验探究]** 要完成“观察冷冻室霜或碘升华视频，只追踪物质去向”，写出本次只改变或重点比较的量，以及判断结论所需的证据。

   **答案**：围绕“固↔气与水循环状态链”只改变一个关键因素，其他条件保持一致；至少取得可比较的数据或清楚现象，不能由一次偶然结果下结论。
5. **[提升·北京题型：解释/论证]** 解释人工降雪与窗上冰花时，为什么必须先追踪物质的初态和末态？

   **答案**：物态变化名称由初态到末态的路径决定；只看最终是固态，无法区分凝固和凝华。
