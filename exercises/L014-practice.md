# L014练习与答案

1. **[基础·概念辨析]** 冷冻室内壁的霜不是液态水冻成的。写出形成霜的初态、末态和名称。

   **答案**：水蒸气由气态直接变为固态冰晶，属于凝华。
2. **[基础·读数/计算]** 窗上冰花通常形成在哪一侧。

   **答案**：室内侧；水蒸气遇冷凝华。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 画“水循环箭头图”：先画水在固态与气态间的变化，再标出比较物质的初态和末态，最后在图旁写出看到的结果。

   **答案**：图中对象：水在固态与气态间的变化；比较或变化：比较物质的初态和末态；结果：可跳过液态直接变化；结论：固态直接变气态叫升华，气态直接变固态叫凝华。
4. **[典型·证据与实验]** 完成“观察冷冻室霜或碘升华视频，只追踪物质去向”时，写出要比较的对象、只改变或重点比较的条件，以及应记录的现象。

   **答案**：围绕“固↔气与水循环状态链”完成一次清楚比较：先定对象和条件，再记录能支持或否定“物质可直接在固态和气态间变化”的现象；一次操作不能外推成普遍定律。
5. **[提升·解释论证]** 解释人工降雪与窗上冰花时，为什么必须先追踪物质的初态和末态？

   **答案**：物态变化名称由初态到末态的路径决定；只看最终是固态，无法区分凝固和凝华。
