# L007练习与答案

1. **[基础·概念辨析]** 同一根橡皮筋先轻拨、再用力拨，主要改变的是：A.音调 B.响度 C.音色 D.声速。

   **答案**：B。用力拨通常增大振幅，因此响度增大。
2. **[基础·读数/计算]** 用力拨同一根弦主要改变什么。

   **答案**：响度；弦的振动频率近似不变。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 画“三种波形对比图”：先画声音的波形与听感，再标出分别比较频率、振幅和波形，最后在图旁写出看到的结果。

   **答案**：图中对象：声音的波形与听感；比较或变化：分别比较频率、振幅和波形；结果：对应音调、响度和音色的差别；结论：频率决定音调，振幅影响响度，波形特征反映音色。
4. **[典型·证据与实验]** 完成“弹不同长度橡皮筋并改变拨动力度”时，写出要比较的对象、只改变或重点比较的条件，以及应记录的现象。

   **答案**：围绕“频率管高低、振幅管强弱、音色辨声源”完成一次清楚比较：先定对象和条件，再记录能支持或否定“声音有音调、响度、音色三种特性”的现象；一次操作不能外推成普遍定律。
5. **[提升·解释论证]** 两列波形频率相同、振幅不同。它们的音调和响度分别怎样比较？

   **答案**：频率相同所以音调相同；振幅较大的声音通常响度较大。
