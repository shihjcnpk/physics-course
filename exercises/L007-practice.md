# L007｜音调、响度和音色别混淆｜10分钟练习

1. **[基础·北京题型：概念辨析]** 同一根橡皮筋先轻拨、再用力拨，主要改变的是：A.音调 B.响度 C.音色 D.声速。

   **答案**：B。用力拨通常增大振幅，因此响度增大。
2. **[基础·北京题型：读数/计算]** 用力拨同一根弦主要改变什么。

   **答案**：响度；弦的振动频率近似不变。关键条件：对象、过程和单位必须配对。
3. **[典型·北京题型：读图作图]** 围绕“三种波形对比图”，标出研究对象、关键方向或变量，并用图得出“频率管高低、振幅管强弱、音色辨声源”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·北京题型：实验探究]** 要完成“弹不同长度橡皮筋并改变拨动力度”，写出本次只改变或重点比较的量，以及判断结论所需的证据。

   **答案**：围绕“频率管高低、振幅管强弱、音色辨声源”只改变一个关键因素，其他条件保持一致；至少取得可比较的数据或清楚现象，不能由一次偶然结果下结论。
5. **[提升·北京题型：解释/论证]** 两列波形频率相同、振幅不同。它们的音调和响度分别怎样比较？

   **答案**：频率相同所以音调相同；振幅较大的声音通常响度较大。
