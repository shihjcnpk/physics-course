# L039练习与答案

1. **[基础·概念辨析]** 完成下面这项任务后，有同学的解释出现“触底数据仍采用”。任务：改变浸入体积、液体种类；完全浸没后再改深度。请指出应补充或改正的关键条件。

   **答案**：先按“控制变量比较称重差”圈定研究对象和条件，再改正该判断；不能只写错误名称。
2. **[基础·读数/计算]** 完全浸没后继续下沉，浮力通常怎样。

   **答案**：若液体密度不变且未触底，浮力不变。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 围绕“浸入体积对比图”，标出研究对象、关键方向或变量，并用图得出“控制变量比较称重差”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·证据与实验]** 本课核心实验怎样保证结论可信？写出主动改变的量、观察测量的量和关键控制条件。

   **答案**：主动改变：排开体积或液体密度，每轮只改一个；观察测量：称重差得到的浮力；关键控制：物体不触底、同一物体和测力计状态；证据记录：空气示数、液中示数与浮力。
5. **[提升·解释论证]** 把下面的核心问题改成可检验的问题，并写出需要取得的证据：物体浸得更深，浮力一定更大吗？

   **答案**：先圈定对象和条件，再用“控制变量比较称重差”连接证据与结论。如果出现“把深度与排开体积混淆”，订正这个判断步骤后，再用一道同类题确认。
