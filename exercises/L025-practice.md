# L025练习与答案

1. **[基础·概念辨析]** 测液体密度时，小京把烧杯和液体的总质量94 g直接除以液体体积60 cm³。这样做对吗？

   **答案**：不对。94 g中包含烧杯质量，必须先减去空烧杯质量，再用液体质量除以同一份液体的体积。
2. **[基础·读数/计算]** 空杯40 g，杯和液体共94 g，液体体积60 cm³，密度。

   **答案**：0.90 g/cm³。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 画“液体密度测量流程图”：先画同一份液体、容器和量筒，再标出先减去容器质量，再读取对应液体体积，最后在图旁写出看到的结果。

   **答案**：图中对象：同一份液体、容器和量筒；比较或变化：先减去容器质量，再读取对应液体体积；结果：得到液体质量和体积这一对数据；结论：用ρ=(m总-m容)/V计算液体密度，质量和体积必须对应同一份液体。
4. **[典型·证据与实验]** 本课核心实验怎样保证结论可信？写出主动改变的量、观察测量的量和关键控制条件。

   **答案**：主动改变：测量类，无自变量；观察测量：同一份液体的质量、体积和密度；关键控制：天平调平、容器质量正确相减、量筒视线水平并减少残留；证据记录：空容器质量、总质量、液体体积与密度。
5. **[提升·解释论证]** 若先量出60 cm³液体，再把液体倒入烧杯称质量，量筒中有少量液体残留，测得密度偏大还是偏小？

   **答案**：倒入烧杯的液体质量对应的实际体积小于记录的60 cm³，却仍用60 cm³作分母，因此测得密度偏小。
