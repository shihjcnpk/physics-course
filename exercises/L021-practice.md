# L021练习与答案

1. **[基础·概念辨析]** 照相机、投影仪、放大镜都用凸透镜。哪一种成的像不能落在光屏上？

   **答案**：放大镜。物体在焦点以内时成正立、放大的虚像，虚像不能用光屏承接。
2. **[基础·读数/计算]** 哪种应用得到不能落在光屏上的放大像。

   **答案**：放大镜；物体在焦点以内时得到正立、放大的虚像。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 画“三种应用对比图”：先画凸透镜成像装置，再标出把物体放在不同物距区间，最后在图旁写出看到的结果。

   **答案**：图中对象：凸透镜成像装置；比较或变化：把物体放在不同物距区间；结果：得到缩小实像、放大实像或放大虚像；结论：照相机、投影仪、放大镜的差别来自物距区间不同。
4. **[典型·证据与实验]** 完成“把物体依次放在2f外、f与2f间、f内，判断像能否在纸屏上承接”时，写出要比较的对象、只改变或重点比较的条件，以及应记录的现象。

   **答案**：围绕“成像区间→像的性质→器件功能”完成一次清楚比较：先定对象和条件，再记录能支持或否定“物距所在区间决定凸透镜的成像用途”的现象；一次操作不能外推成普遍定律。
5. **[提升·解释论证]** 同一凸透镜既能做照相机模型，也能做放大镜。决定用途的关键条件是什么？

   **答案**：关键是物距与焦距的关系。物体在焦点外可成实像供照相或投影；物体在焦点内成正立、放大的虚像供放大观察。
