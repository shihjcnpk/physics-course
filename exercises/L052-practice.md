# L052练习与答案

1. **[基础·概念辨析]** 完成下面这项任务后，有同学的解释出现“电路图元件画错”。任务：电池、灯泡、开关试接，先检查短路风险。请指出应补充或改正的关键条件。

   **答案**：先按“电源—导线—用电器—开关闭环”圈定研究对象和条件，再改正该判断；不能只写错误名称。
2. **[基础·读数/计算]** 开关闭合但灯不亮先查什么。

   **答案**：通路是否完整、接触是否可靠。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 围绕“最简电路图”，标出研究对象、关键方向或变量，并用图得出“电源—导线—用电器—开关闭环”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·证据与实验]** 完成“电池、灯泡、开关试接，先检查短路风险”时，写出要比较的对象、只改变或重点比较的条件，以及应记录的现象。

   **答案**：围绕“电源—导线—用电器—开关闭环”完成一次清楚比较：先定对象和条件，再记录能支持或否定“持续电流需要电源和闭合通路”的现象；一次操作不能外推成普遍定律。
5. **[提升·解释论证]** 把下面的核心问题改成可检验的问题，并写出需要取得的证据：灯泡亮起来，电流必须走怎样的路？

   **答案**：先圈定对象和条件，再用“电源—导线—用电器—开关闭环”连接证据与结论。如果出现“把电流消耗掉”，订正这个判断步骤后，再用一道同类题确认。
