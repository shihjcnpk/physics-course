# L017练习与答案

1. **[基础·概念辨析]** 人站在平面镜前1.2 m处，向镜面靠近0.2 m。此时像到人的距离是多少？

   **答案**：物距变为1.0 m，像距也是1.0 m，像到人的距离2.0 m。
2. **[基础·读数/计算]** 人离镜1 m，像离人多远。

   **答案**：2 m；像在镜后1 m。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 画“玻璃板成像图”：先画物体、平面镜和像，再标出改变物体到镜面的距离，最后在图旁写出看到的结果。

   **答案**：图中对象：物体、平面镜和像；比较或变化：改变物体到镜面的距离；结果：像距同步改变且始终与物距相等；结论：平面镜成等大正立虚像，像与物关于镜面对称。
4. **[典型·证据与实验]** 本课核心实验怎样保证结论可信？写出主动改变的量、观察测量的量和关键控制条件。

   **答案**：主动改变：物距；观察测量：像距、像大小和能否承接；关键控制：同一玻璃板、相同物体、测量基准；证据记录：多组物距像距及光屏检验。
5. **[提升·解释论证]** 平面镜实验中为何用玻璃板而不用不透明镜子？为何还要两支相同蜡烛？

   **答案**：玻璃板既成像又能看到镜后蜡烛，便于定位像；相同蜡烛与像重合可比较像与物的大小。
