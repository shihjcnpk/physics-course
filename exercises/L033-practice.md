# L033练习与答案

1. **[基础·概念辨析]** 完成下面这项任务后，有同学的解释出现“反向相减后漏合力方向”。任务：用两端钩码拉卡片，先比较同向与反向合力，再让反向二力等大观察平衡。请指出应补充或改正的关键条件。

   **答案**：先按“先定正方向；同向相加、反向相减；合力为零时检查同体等大反向共线”圈定研究对象和条件，再改正该判断；不能只写错误名称。
2. **[基础·读数/计算]** 物体受向右6 N和向左4 N的力，合力怎样。

   **答案**：合力为2 N，方向向右；若两力等大反向且作用在同一物体同一直线上，合力才为零。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 围绕“同一直线二力合成与平衡图”，标出研究对象、关键方向或变量，并用图得出“先定正方向；同向相加、反向相减；合力为零时检查同体等大反向共线”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·证据与实验]** 完成“用两端钩码拉卡片，先比较同向与反向合力，再让反向二力等大观察平衡”时，写出要比较的对象、只改变或重点比较的条件，以及应记录的现象。

   **答案**：围绕“先定正方向；同向相加、反向相减；合力为零时检查同体等大反向共线”完成一次清楚比较：先定对象和条件，再记录能支持或否定“同一直线上同向二力相加、反向二力相减；合力为零是二力平衡的特殊情况”的现象；一次操作不能外推成普遍定律。
5. **[提升·解释论证]** 把下面的核心问题改成可检验的问题，并写出需要取得的证据：两个方向相同或相反的力一起作用，总效果怎样判断？

   **答案**：先圈定对象和条件，再用“先定正方向；同向相加、反向相减；合力为零时检查同体等大反向共线”连接证据与结论。如果出现“把相互作用力当平衡力”，订正这个判断步骤后，再用一道同类题确认。
