# L062练习与答案

1. **[基础·概念辨析]** 完成下面这项任务后，有同学的解释出现“小时秒混用”。任务：读取家用电能表前后示数，计算一段时间的用电量。请指出应补充或改正的关键条件。

   **答案**：先按“电压、电流和时间共同决定电功”圈定研究对象和条件，再改正该判断；不能只写错误名称。
2. **[基础·读数/计算]** 220 V、2 A电器工作10 s，电功。

   **答案**：4400 J。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 围绕“电能流与电能表图”，标出研究对象、关键方向或变量，并用图得出“电压、电流和时间共同决定电功”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·证据与实验]** 把例题信息整理成“对象—条件—关系—结论”四格，不增加题目没有给出的条件。

   **答案**：对象和条件必须来自题目；关系使用“电压、电流和时间共同决定电功”；最后用单位或物理意义检查结论。
5. **[提升·解释论证]** 把下面的核心问题改成可检验的问题，并写出需要取得的证据：电器工作一段时间，转化了多少电能？

   **答案**：先圈定对象和条件，再用“电压、电流和时间共同决定电功”连接证据与结论。如果出现“电功与功率混淆”，订正这个判断步骤后，再用一道同类题确认。
