# L003练习与答案

1. **[基础·概念辨析]** 甲车10 s行80 m，乙车12 s行90 m。谁更快？不能只写答案，要给出公平比较的数据。

   **答案**：甲车8 m/s，乙车7.5 m/s，所以甲更快。
2. **[基础·读数/计算]** 60 m用12 s，速度是多少。

   **答案**：5 m/s，表示每秒通过5 m。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 画“路程时间条形图”：先画同一运动物体，再标出每段都取相同的1秒，最后在图旁写出看到的结果。

   **答案**：图中对象：同一运动物体；比较或变化：每段都取相同的1秒；结果：1秒内路程越大，运动越快；结论：速度就是单位时间通过的路程，v=s/t。
4. **[典型·证据与实验]** 把例题信息整理成“对象—条件—关系—结论”四格，不增加题目没有给出的条件。

   **答案**：对象和条件必须来自题目；关系使用“单位时间通过的路程”；最后用单位或物理意义检查结论。
5. **[提升·解释论证]** 只知道甲路程更长，能否判定甲更快？写出还需要的证据。

   **答案**：不能。还需两车所用时间，或给出相同时间内的路程、相同路程所用时间。
