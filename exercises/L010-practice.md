# L010练习与答案

1. **[基础·概念辨析]** 冬天眼镜从室外进入暖屋后出现小水珠。它的初态和末态分别是什么？

   **答案**：空气中的水蒸气（气态）变成小水滴（液态），属于液化。
2. **[基础·读数/计算]** 冰变水属于什么变化。

   **答案**：熔化：固态到液态。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 画“三态六箭头图”：先画同一种物质，再标出改变吸放热条件，最后在图旁写出看到的结果。

   **答案**：图中对象：同一种物质；比较或变化：改变吸放热条件；结果：固、液、气三态互相转化；结论：判断物态变化要先写初态和末态，再按箭头命名。
4. **[典型·证据与实验]** 完成“观察冰融化和杯外水珠，只先标起点与终点”时，写出要比较的对象、只改变或重点比较的条件，以及应记录的现象。

   **答案**：围绕“三态之间六种变化方向”完成一次清楚比较：先定对象和条件，再记录能支持或否定“同种物质可处于固液气三态”的现象；一次操作不能外推成普遍定律。
5. **[提升·解释论证]** 把‘杯外水珠是杯内水渗出’改造成可检验的实验方案。

   **答案**：把密封良好的空杯和装冷水杯置于同一环境；若只有冷杯外出现水珠，支持空气中水蒸气遇冷液化。
