# L010｜三态与物态变化地图｜10分钟练习

1. **[基础·北京题型：概念辨析]** 冬天眼镜从室外进入暖屋后出现小水珠。它的初态和末态分别是什么？

   **答案**：空气中的水蒸气（气态）变成小水滴（液态），属于液化。
2. **[基础·北京题型：读数/计算]** 冰变水属于什么变化。

   **答案**：熔化：固态到液态。关键条件：对象、过程和单位必须配对。
3. **[典型·北京题型：读图作图]** 围绕“三态六箭头图”，标出研究对象、关键方向或变量，并用图得出“三态之间六种变化方向”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·北京题型：实验探究]** 要完成“观察冰融化和杯外水珠，只先标起点与终点”，写出本次只改变或重点比较的量，以及判断结论所需的证据。

   **答案**：围绕“三态之间六种变化方向”只改变一个关键因素，其他条件保持一致；至少取得可比较的数据或清楚现象，不能由一次偶然结果下结论。
5. **[提升·北京题型：解释/论证]** 把‘杯外水珠是杯内水渗出’改造成可检验的实验方案。

   **答案**：把密封良好的空杯和装冷水杯置于同一环境；若只有冷杯外出现水珠，支持空气中水蒸气遇冷液化。
