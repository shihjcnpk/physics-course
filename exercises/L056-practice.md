# L056练习与答案

1. **[基础·概念辨析]** 完成下面这项任务后，有同学的解释出现“正负接线错”。任务：辨量程和分度值，再把电压表跨接在灯泡两端。请指出应补充或改正的关键条件。

   **答案**：先按“电压表并联、正进负出、量程合适”圈定研究对象和条件，再改正该判断；不能只写错误名称。
2. **[基础·读数/计算]** 0～3 V量程每小格0.1 V，指23格。

   **答案**：2.3 V。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 围绕“电压表接线图”，标出研究对象、关键方向或变量，并用图得出“电压表并联、正进负出、量程合适”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·证据与实验]** 本课核心实验怎样保证结论可信？写出主动改变的量、观察测量的量和关键控制条件。

   **答案**：主动改变：测量类，无自变量；观察测量：元件两端电压；关键控制：量程、正负接线和并联端点；证据记录：量程、分度值和示数。
5. **[提升·解释论证]** 把下面的核心问题改成可检验的问题，并写出需要取得的证据：怎样测出灯泡两端的电压而不改变原来的支路？

   **答案**：先圈定对象和条件，再用“电压表并联、正进负出、量程合适”连接证据与结论。如果出现“把电压表串联”，订正这个判断步骤后，再用一道同类题确认。
