# L023练习与答案

1. **概念判断**：用自己的话解释“密度是单位体积的质量”。  
   **答案**：必须同时说出物理对象和关系：质量—体积比率模型。只重复标题不算完成。
2. **条件辨认**：写出ρ=m/V中各量对应的对象，并说一个不能直接使用它的情形。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C6密度单位错”。
3. **图示应用**：请画一张“等体积质量对比图”，用图解释“质量—体积比率模型”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：质量178 g、体积20 cm³，密度。  
   **答案**：8.9 g/cm³。关键模型：质量—体积比率模型。
5. **情境与错因侦探**：同学完成“比较等体积水和食用油质量，统一到1 cm³”后出现“C5比值颠倒”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C5比值颠倒**。先检查与“质量—体积比率模型”直接相关的对象和条件，再决定重画图、重读数或重算。
