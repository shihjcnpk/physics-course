# L048练习与答案

1. **概念判断**：用自己的话解释“热传递和做功都能改变内能”。  
   **答案**：必须同时说出物理对象和关系：能量转移与能量转化两类路径。只重复标题不算完成。
2. **条件辨认**：不用公式，只用“能量转移与能量转化两类路径”判断并说明条件。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C2两路径混淆”。
3. **图示应用**：请画一张“内能路径图”，用图解释“能量转移与能量转化两类路径”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：压缩空气使其变热属于哪种。  
   **答案**：做功，机械能转化为内能。关键模型：能量转移与能量转化两类路径。
5. **情境与错因侦探**：同学完成“搓手、弯折铁丝、接触温水，给路径分类”后出现“C1热量说成物体含有”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C1热量说成物体含有**。先检查与“能量转移与能量转化两类路径”直接相关的对象和条件，再决定重画图、重读数或重算。
