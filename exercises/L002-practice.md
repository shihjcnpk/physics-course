# L002练习与答案

1. **概念判断**：用自己的话解释“机械运动是位置随时间改变”。  
   **答案**：必须同时说出物理对象和关系：相对参照物比较位置。只重复标题不算完成。
2. **条件辨认**：不用公式，只用“相对参照物比较位置”判断并说明条件。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C4漏参照物”。
3. **图示应用**：请画一张“参照物位置对比图”，用图解释“相对参照物比较位置”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：坐在行驶列车中的人相对座椅静止、相对站台运动。  
   **答案**：两种说法都对，关键是参照物不同。关键模型：相对参照物比较位置。
5. **情境与错因侦探**：同学完成“玩具车旁放橡皮，分别以桌面和车为参照观察”后出现“C1把运动说成绝对”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C1把运动说成绝对**。先检查与“相对参照物比较位置”直接相关的对象和条件，再决定重画图、重读数或重算。
