# L002｜运动和静止：先选参照物｜10分钟练习

1. **[基础·北京题型：概念辨析]** 【2024北京中考第3题改编】火箭升空时，下列判断正确的是：A.相对发射塔静止 B.相对地面运动 C.发射塔相对地面运动 D.运动与参照物无关。

   **答案**：B。火箭相对地面的位置随时间改变。
2. **[基础·北京题型：读数/计算]** 坐在行驶列车中的人相对座椅静止、相对站台运动。

   **答案**：两种说法都对，关键是参照物不同。关键条件：对象、过程和单位必须配对。
3. **[典型·北京题型：读图作图]** 围绕“参照物位置对比图”，标出研究对象、关键方向或变量，并用图得出“相对参照物比较位置”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·北京题型：实验探究]** 要完成“玩具车旁放橡皮，分别以桌面和车为参照观察”，写出本次只改变或重点比较的量，以及判断结论所需的证据。

   **答案**：围绕“相对参照物比较位置”只改变一个关键因素，其他条件保持一致；至少取得可比较的数据或清楚现象，不能由一次偶然结果下结论。
5. **[提升·北京题型：解释/论证]** 并排行驶的两列车中，乘客觉得邻车后退。用两个参照物解释为何不矛盾。

   **答案**：以本车为参照，邻车相对位置向后变；以站台为参照，邻车仍可能向前。参照物不同，结论可以不同。
