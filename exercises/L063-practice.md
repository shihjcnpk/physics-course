# L063练习与答案

1. **[基础·概念辨析]** 完成下面这项任务后，有同学的解释出现“使灯泡长时间超过额定电压”。任务：调变阻器使灯泡在低于和等于额定电压的状态工作，记录亮度与U、I。请指出应补充或改正的关键条件。

   **答案**：先按“同一工作状态测U和I后相乘”圈定研究对象和条件，再改正该判断；不能只写错误名称。
2. **[基础·读数/计算]** 额定2.5 V时0.3 A，额定功率。

   **答案**：0.75 W。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 围绕“测功率电路图”，标出研究对象、关键方向或变量，并用图得出“同一工作状态测U和I后相乘”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·证据与实验]** 本课核心实验怎样保证结论可信？写出主动改变的量、观察测量的量和关键控制条件。

   **答案**：主动改变：小灯泡实际电压；观察测量：实际电流、功率和亮度；关键控制：同一灯泡、接线、量程和不超过额定电压；证据记录：低于和等于额定电压时的U、I、P。
5. **[提升·解释论证]** 把下面的核心问题改成可检验的问题，并写出需要取得的证据：小灯泡在不同电压下亮度为何不同？

   **答案**：先圈定对象和条件，再用“同一工作状态测U和I后相乘”连接证据与结论。如果出现“把实际与额定混用”，订正这个判断步骤后，再用一道同类题确认。
