# L018练习与答案

1. **[基础·概念辨析]** 一束光从空气斜射入水。画图前必须先画哪条辅助线？折射光线相对入射方向怎样偏？

   **答案**：先过入射点画法线；从空气斜入水时折射光线向法线偏。
2. **[基础·读数/计算]** 从空气斜射入水，光线通常靠近哪条线。

   **答案**：法线。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 画“空气水界面光路图”：先画斜射到界面的光线，再标出让光从一种介质斜射入另一种介质，最后在图旁写出看到的结果。

   **答案**：图中对象：斜射到界面的光线；比较或变化：让光从一种介质斜射入另一种介质；结果：传播方向在界面处改变；结论：光斜入不同介质通常发生折射；从空气斜入水时折向法线。
4. **[典型·证据与实验]** 完成“激光斜射入水，观察并画入射与折射路径”时，写出要比较的对象、只改变或重点比较的条件，以及应记录的现象。

   **答案**：围绕“入射介质—界面—折射光线模型”完成一次清楚比较：先定对象和条件，再记录能支持或否定“光斜入不同介质时传播方向通常改变”的现象；一次操作不能外推成普遍定律。
5. **[提升·解释论证]** 筷子看起来上折并非筷子真的弯了。按‘光从哪里来—在哪里折射—眼睛怎样反向判断’解释。

   **答案**：水中筷子反射的光在水面折射后进入眼睛；眼睛按直线反向判断光源位置，于是看到较浅的虚像。
