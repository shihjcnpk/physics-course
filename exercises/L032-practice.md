# L032练习与答案

1. **概念判断**：用自己的话解释“一切物体都有保持原运动状态的性质”。  
   **答案**：必须同时说出物理对象和关系：刹车前后分别比较人和车状态。只重复标题不算完成。
2. **条件辨认**：不用公式，只用“刹车前后分别比较人和车状态”判断并说明条件。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C4漏原状态”。
3. **图示应用**：请画一张“刹车状态时间轴”，用图解释“刹车前后分别比较人和车状态”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：跳远助跑为什么有用。  
   **答案**：起跳后身体因惯性保持较大向前速度。关键模型：刹车前后分别比较人和车状态。
5. **情境与错因侦探**：同学完成“抽走纸片观察硬币落杯，再口述前后状态”后出现“C1说“受到惯性力””。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C1说“受到惯性力”**。先检查与“刹车前后分别比较人和车状态”直接相关的对象和条件，再决定重画图、重读数或重算。
