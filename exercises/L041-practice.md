# L041练习与答案

1. **概念判断**：用自己的话解释“浮沉取决于竖直方向浮力和重力关系”。  
   **答案**：必须同时说出物理对象和关系：F浮与G比较；漂浮时相等。只重复标题不算完成。
2. **条件辨认**：不用公式，只用“F浮与G比较；漂浮时相等”判断并说明条件。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C3浮沉力箭头错”。
3. **图示应用**：请画一张“浮沉三状态图”，用图解释“F浮与G比较；漂浮时相等”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：漂浮物质量增大后排水怎样变。  
   **答案**：在仍能漂浮且液体不变时，会排开更多水，直到浮力重新等于重力。关键模型：F浮与G比较；漂浮时相等。
5. **情境与错因侦探**：同学完成“橡皮泥先团成球再捏成船形放水中”后出现“C2只比较材料密度”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C2只比较材料密度**。先检查与“F浮与G比较；漂浮时相等”直接相关的对象和条件，再决定重画图、重读数或重算。
