# L016练习与答案

1. **[基础·概念辨析]** 入射光线与镜面夹角30°，反射角是多少？小京答30°，错在什么地方？

   **答案**：反射角为60°。入射角和反射角都以法线为基准，不以镜面为基准。
2. **[基础·读数/计算]** 入射光与镜面夹30°，反射角是多少。

   **答案**：60°；入射角和反射角都相对法线测量。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 画“反射光路图”：先画入射光线、法线和反射光线，再标出改变入射光线相对法线的角度，最后在图旁写出看到的结果。

   **答案**：图中对象：入射光线、法线和反射光线；比较或变化：改变入射光线相对法线的角度；结果：反射光线随之改变且两角相等；结论：反射角等于入射角；角度都从法线量起。
4. **[典型·证据与实验]** 本课核心实验怎样保证结论可信？写出主动改变的量、观察测量的量和关键控制条件。

   **答案**：主动改变：入射角；观察测量：反射角和光路位置；关键控制：同一镜面、入射点和量角方法；证据记录：不少于三组i与r及翻折光屏现象。
5. **[提升·解释论证]** 探究反射规律为什么要改变入射角测多组数据，并让纸板折转？

   **答案**：多组角度用于检验反射角始终等于入射角，避免偶然；折转纸板用于检验三线是否在同一平面。
