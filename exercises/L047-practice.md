# L047练习与答案

1. **[基础·概念辨析]** 完成下面这项任务后，有同学的解释出现“内能等同热量”。任务：冷水与热水各滴一滴色素，只比较扩散快慢。请指出应补充或改正的关键条件。

   **答案**：先按“从扩散和温度变化连接微观运动模型”圈定研究对象和条件，再改正该判断；不能只写错误名称。
2. **[基础·读数/计算]** 同一物体、状态不变时温度升高，分子运动和内能通常怎样。

   **答案**：分子无规则运动更剧烈，内能通常增大。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 围绕“扩散微粒图”，标出研究对象、关键方向或变量，并用图得出“从扩散和温度变化连接微观运动模型”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·证据与实验]** 完成“冷水与热水各滴一滴色素，只比较扩散快慢”时，写出要比较的对象、只改变或重点比较的条件，以及应记录的现象。

   **答案**：围绕“从扩散和温度变化连接微观运动模型”完成一次清楚比较：先定对象和条件，再记录能支持或否定“分子不停做无规则运动；内能包含分子动能和分子间相互作用势能”的现象；一次操作不能外推成普遍定律。
5. **[提升·解释论证]** 把下面的核心问题改成可检验的问题，并写出需要取得的证据：打开香水后，远处为什么也能闻到？

   **答案**：先圈定对象和条件，再用“从扩散和温度变化连接微观运动模型”连接证据与结论。如果出现“分子热运动等同物体移动”，订正这个判断步骤后，再用一道同类题确认。
