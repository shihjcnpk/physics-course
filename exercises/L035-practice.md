# L035练习与答案

1. **概念判断**：用自己的话解释“液体内部向各方向有压强”。  
   **答案**：必须同时说出物理对象和关系：同种液体压强随深度增加；同深度看密度。只重复标题不算完成。
2. **条件辨认**：不用公式，只用“同种液体压强随深度增加；同深度看密度”判断并说明条件。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C8一次数据下结论”。
3. **图示应用**：请画一张“压强计深度图”，用图解释“同种液体压强随深度增加；同深度看密度”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：研究深度影响时保持什么相同。  
   **答案**：液体种类和探头方向等相同。关键模型：同种液体压强随深度增加；同深度看密度。
5. **情境与错因侦探**：同学完成“改变探头深度、方向和液体种类，观察U形管高度差”后出现“C4把离容器底距离当深度”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C4把离容器底距离当深度**。先检查与“同种液体压强随深度增加；同深度看密度”直接相关的对象和条件，再决定重画图、重读数或重算。
