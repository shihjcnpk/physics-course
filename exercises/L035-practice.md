# L035练习与答案

1. **[基础·概念辨析]** 完成下面这项任务后，有同学的解释出现“一次数据下结论”。任务：改变探头深度、方向和液体种类，观察U形管高度差。请指出应补充或改正的关键条件。

   **答案**：先按“同种液体压强随深度增加；同深度看密度”圈定研究对象和条件，再改正该判断；不能只写错误名称。
2. **[基础·读数/计算]** 研究深度影响时保持什么相同。

   **答案**：液体种类和探头方向等相同。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 围绕“压强计深度图”，标出研究对象、关键方向或变量，并用图得出“同种液体压强随深度增加；同深度看密度”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·证据与实验]** 本课核心实验怎样保证结论可信？写出主动改变的量、观察测量的量和关键控制条件。

   **答案**：主动改变：深度、方向或液体密度，每轮只改一个；观察测量：U形管液面高度差；关键控制：同一探头、零点和其余条件；证据记录：条件表与稳定后的高度差。
5. **[提升·解释论证]** 把下面的核心问题改成可检验的问题，并写出需要取得的证据：潜水越深，耳朵为什么越不舒服？

   **答案**：先圈定对象和条件，再用“同种液体压强随深度增加；同深度看密度”连接证据与结论。如果出现“把离容器底距离当深度”，订正这个判断步骤后，再用一道同类题确认。
