# L068｜磁场对电流的作用与电动机｜10分钟练习

1. **[基础·北京题型：概念辨析]** 在“让通电线框在磁场中运动并分别反向电流、磁场”中，有同学出现了“只反一项却判方向不变”。这个结论可靠吗？

   **答案**：不可靠。应先按“电能→机械能；电流或磁场反向则受力反向”核对研究对象和条件。
2. **[基础·北京题型：读数/计算]** 电动机主要把什么能转为什么能。

   **答案**：电能转化为机械能。关键条件：对象、过程和单位必须配对。
3. **[典型·北京题型：读图作图]** 围绕“电动机受力图”，标出研究对象、关键方向或变量，并用图得出“电能→机械能；电流或磁场反向则受力反向”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·北京题型：实验探究]** 要完成“让通电线框在磁场中运动并分别反向电流、磁场”，写出本次只改变或重点比较的量，以及判断结论所需的证据。

   **答案**：围绕“电能→机械能；电流或磁场反向则受力反向”只改变一个关键因素，其他条件保持一致；至少取得可比较的数据或清楚现象，不能由一次偶然结果下结论。
5. **[提升·北京题型：解释/论证]** 把“通电线圈为什么能转起来？”改成可检验的问题，并写出需要取得的证据。

   **答案**：先圈定对象和条件，再用“电能→机械能；电流或磁场反向则受力反向”连接证据与结论。如果出现“与发电机混淆”，订正这个判断步骤后，再用一道同类题确认。
