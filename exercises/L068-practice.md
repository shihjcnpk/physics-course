# L068练习与答案

1. **概念判断**：用自己的话解释“通电导线在磁场中受力”。  
   **答案**：必须同时说出物理对象和关系：电能→机械能；电流或磁场反向则受力反向。只重复标题不算完成。
2. **条件辨认**：不用公式，只用“电能→机械能；电流或磁场反向则受力反向”判断并说明条件。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C3只反一项却判方向不变”。
3. **图示应用**：请画一张“电动机受力图”，用图解释“电能→机械能；电流或磁场反向则受力反向”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：电动机主要把什么能转为什么能。  
   **答案**：电能转化为机械能。关键模型：电能→机械能；电流或磁场反向则受力反向。
5. **情境与错因侦探**：同学完成“让通电线框在磁场中运动并分别反向电流、磁场”后出现“C2与发电机混淆”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C2与发电机混淆**。先检查与“电能→机械能；电流或磁场反向则受力反向”直接相关的对象和条件，再决定重画图、重读数或重算。
