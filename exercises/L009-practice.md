# L009练习与答案

1. **[基础·概念辨析]** 温度计液柱顶端在0 ℃以下第4小格，每小格1 ℃。俯视读数是否规范？正确示数是多少？

   **答案**：不规范，视线应与液柱顶端相平；示数为−4 ℃。
2. **[基础·读数/计算]** 温度计示数在0下4格、每格1℃。

   **答案**：−4℃；视线与液柱顶端相平。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 画“温度计读数图”：先画温度计内的测温液体，再标出让温度改变并观察液柱，最后在图旁写出看到的结果。

   **答案**：图中对象：温度计内的测温液体；比较或变化：让温度改变并观察液柱；结果：液柱位置随温度规律变化；结论：温度计把冷热程度转换为可读刻度，读数时视线要与液柱顶端相平。
4. **[典型·证据与实验]** 本课核心实验怎样保证结论可信？写出主动改变的量、观察测量的量和关键控制条件。

   **答案**：主动改变：被测对象；观察测量：温度计示数；关键控制：温度计量程、浸入位置、稳定等待和视线；证据记录：带正负号与℃的读数。
5. **[提升·解释论证]** 手先放冷水再放温水，与先放热水再放温水感受不同，说明测温为什么不能只靠感觉？

   **答案**：同一杯温水因手原来的状态不同而感觉不同，感觉受比较基准影响；应使用温度计获得可比较数据。
