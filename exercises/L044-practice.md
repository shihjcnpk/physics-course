# L044｜动能、势能与机械能转化｜10分钟练习

1. **[基础·北京题型：概念辨析]** 在“滚小球下斜面撞纸盒，改变高度或质量比较”中，有同学出现了“把能量说成力”。这个结论可靠吗？

   **答案**：不可靠。应先按“动能↔势能，考虑阻力时部分转为内能”核对研究对象和条件。
2. **[基础·北京题型：读数/计算]** 小球从高处下滑时能量怎样变。

   **答案**：重力势能减小、动能增大。关键条件：对象、过程和单位必须配对。
3. **[典型·北京题型：读图作图]** 围绕“秋千能量条图”，标出研究对象、关键方向或变量，并用图得出“动能↔势能，考虑阻力时部分转为内能”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·北京题型：实验探究]** 要完成“滚小球下斜面撞纸盒，改变高度或质量比较”，写出本次只改变或重点比较的量，以及判断结论所需的证据。

   **答案**：围绕“动能↔势能，考虑阻力时部分转为内能”只改变一个关键因素，其他条件保持一致；至少取得可比较的数据或清楚现象，不能由一次偶然结果下结论。
5. **[提升·北京题型：解释/论证]** 把“秋千为什么能来回摆但不会越摆越高？”改成可检验的问题，并写出需要取得的证据。

   **答案**：先圈定对象和条件，再用“动能↔势能，考虑阻力时部分转为内能”连接证据与结论。如果出现“忽略系统与阻力”，订正这个判断步骤后，再用一道同类题确认。
