# L044练习与答案

1. **概念判断**：用自己的话解释“运动和位置可储存机械能”。  
   **答案**：必须同时说出物理对象和关系：动能↔势能，考虑阻力时部分转为内能。只重复标题不算完成。
2. **条件辨认**：不用公式，只用“动能↔势能，考虑阻力时部分转为内能”判断并说明条件。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C1把能量说成力”。
3. **图示应用**：请画一张“秋千能量条图”，用图解释“动能↔势能，考虑阻力时部分转为内能”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：小球从高处下滑时能量怎样变。  
   **答案**：重力势能减小、动能增大。关键模型：动能↔势能，考虑阻力时部分转为内能。
5. **情境与错因侦探**：同学完成“滚小球下斜面撞纸盒，改变高度或质量比较”后出现“C2忽略系统与阻力”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C2忽略系统与阻力**。先检查与“动能↔势能，考虑阻力时部分转为内能”直接相关的对象和条件，再决定重画图、重读数或重算。
