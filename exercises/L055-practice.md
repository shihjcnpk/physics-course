# L055练习与答案

1. **[基础·概念辨析]** 完成下面这项任务后，有同学的解释出现“把电流当消耗品”。任务：换测多个位置和不同灯泡，记录三组数据。请指出应补充或改正的关键条件。

   **答案**：先按“节点电流守恒模型”圈定研究对象和条件，再改正该判断；不能只写错误名称。
2. **[基础·读数/计算]** 并联两支路0.2 A与0.3 A，干路。

   **答案**：0.5 A。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 围绕“节点电流箭头图”，标出研究对象、关键方向或变量，并用图得出“节点电流守恒模型”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·证据与实验]** 本课核心实验怎样保证结论可信？写出主动改变的量、观察测量的量和关键控制条件。

   **答案**：主动改变：测量位置或支路；观察测量：各处电流；关键控制：电源、灯泡组合、量程和连接方式；证据记录：不同位置和不同灯泡组合的多组电流。
5. **[提升·解释论证]** 把下面的核心问题改成可检验的问题，并写出需要取得的证据：电流经过灯泡后会被“用掉”吗？

   **答案**：先圈定对象和条件，再用“节点电流守恒模型”连接证据与结论。如果出现“只测一组”，订正这个判断步骤后，再用一道同类题确认。
