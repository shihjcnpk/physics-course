# L053练习与答案

1. **[基础·概念辨析]** 完成下面这项任务后，有同学的解释出现“漏节点”。任务：用两灯搭串联与并联，断开一灯观察另一灯。请指出应补充或改正的关键条件。

   **答案**：先按“从电流路径识别连接方式”圈定研究对象和条件，再改正该判断；不能只写错误名称。
2. **[基础·读数/计算]** 家庭灯为什么并联。

   **答案**：各支路可独立工作且两端电压相同。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 围绕“串并联路径图”，标出研究对象、关键方向或变量，并用图得出“从电流路径识别连接方式”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·证据与实验]** 完成“用两灯搭串联与并联，断开一灯观察另一灯”时，写出要比较的对象、只改变或重点比较的条件，以及应记录的现象。

   **答案**：围绕“从电流路径识别连接方式”完成一次清楚比较：先定对象和条件，再记录能支持或否定“串联一条路径，并联多条支路”的现象；一次操作不能外推成普遍定律。
5. **[提升·解释论证]** 把下面的核心问题改成可检验的问题，并写出需要取得的证据：家里一盏灯坏了，其他灯为什么还能亮？

   **答案**：先圈定对象和条件，再用“从电流路径识别连接方式”连接证据与结论。如果出现“按元件摆放形状判断”，订正这个判断步骤后，再用一道同类题确认。
