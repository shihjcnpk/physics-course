# L008练习与答案

1. **概念判断**：用自己的话解释“声可传递信息和能量”。  
   **答案**：必须同时说出物理对象和关系：声源—传播—接收三处分析。只重复标题不算完成。
2. **条件辨认**：不用公式，只用“声源—传播—接收三处分析”判断并说明条件。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C4忽略情境”。
3. **图示应用**：请画一张“噪声三环节图”，用图解释“声源—传播—接收三处分析”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：给临街房间选降噪措施。  
   **答案**：关窗主要在传播途径减弱噪声。关键模型：声源—传播—接收三处分析。
5. **情境与错因侦探**：同学完成“用软布包住响铃，比较声源与传播途径控制”后出现“C2控制环节混乱”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C2控制环节混乱**。先检查与“声源—传播—接收三处分析”直接相关的对象和条件，再决定重画图、重读数或重算。
