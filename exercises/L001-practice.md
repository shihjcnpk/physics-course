# L001练习与答案

1. **[基础·概念辨析]** 小京用分度值为1 mm的刻度尺测书宽，记录为18.6，但没有写单位。这个结果是否完整？

   **答案**：不完整。测量值必须由数值和单位共同组成，应按实际读数补写单位。
2. **[基础·读数/计算]** 尺上12.30 cm表示精确到毫米并估读一位。

   **答案**：12.30 cm；末位是估读。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 画“刻度尺读数图”：先画刻度尺与被测物体，再标出分度值、起点和末端读数，最后在图旁写出看到的结果。

   **答案**：图中对象：刻度尺与被测物体；比较或变化：分度值、起点和末端读数；结果：读数由准确值和估读值组成；结论：测量结果必须写数值和单位；估读不是随意猜。
4. **[典型·证据与实验]** 本课核心实验怎样保证结论可信？写出主动改变的量、观察测量的量和关键控制条件。

   **答案**：主动改变：测量类，无自变量；观察测量：长度和时间读数；关键控制：量程、分度值、视线和起止点；证据记录：原始读数、估读位与单位。
5. **[提升·解释论证]** 同一支铅笔测三次得到17.82 cm、17.81 cm、18.92 cm。指出异常数据并说明处理办法。

   **答案**：18.92 cm明显偏离，先核查起点、分度值和读数；确认操作错误后重测，不能把异常值直接放入平均值。
