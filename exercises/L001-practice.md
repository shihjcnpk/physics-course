# L001练习与答案

1. **概念判断**：用自己的话解释“测量值由数值和单位组成”。  
   **答案**：必须同时说出物理对象和关系：选量程、分度值、估读并记录。只重复标题不算完成。
2. **条件辨认**：不用公式，只用“选量程、分度值、估读并记录”判断并说明条件。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C9漏读分度值”。
3. **图示应用**：请画一张“刻度尺读数图”，用图解释“选量程、分度值、估读并记录”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：尺上12.30 cm表示精确到毫米并估读一位。  
   **答案**：12.30 cm；末位是估读。关键模型：选量程、分度值、估读并记录。
5. **情境与错因侦探**：同学完成“测书本宽度并测30次脉搏时间”后出现“C6单位错误”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C6单位错误**。先检查与“选量程、分度值、估读并记录”直接相关的对象和条件，再决定重画图、重读数或重算。
