# L028｜重力：方向总指向哪里｜10分钟练习

1. **[基础·北京题型：概念辨析]** 在“悬挂小重物观察重垂线，再在斜面图画重力”中，有同学忽略了“C6质量单位未化kg”。这个结论可靠吗？

   **答案**：不可靠。应先按“重心处竖直向下”核对研究对象和条件。
2. **[基础·北京题型：读数/计算]** 2 kg物体重力约多少，取g=10 N/kg。

   **答案**：20 N，方向竖直向下。关键条件：对象、过程和单位必须配对。
3. **[典型·北京题型：读图作图]** 围绕“斜面重力图”，标出研究对象、关键方向或变量，并用图得出“重心处竖直向下”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·北京题型：实验探究]** 要完成“悬挂小重物观察重垂线，再在斜面图画重力”，写出本次只改变或重点比较的量，以及判断结论所需的证据。

   **答案**：围绕“重心处竖直向下”只改变一个关键因素，其他条件保持一致；至少取得可比较的数据或清楚现象，不能由一次偶然结果下结论。
5. **[提升·北京题型：解释/论证]** 把“站在斜坡上，重力会沿斜坡向下吗？”改成可检验的问题，并写出需要取得的证据。

   **答案**：先圈定对象和条件，再用“重心处竖直向下”连接证据与结论。若出现“C3把竖直当垂直斜面”，归入 **C3把竖直当垂直斜面** 并只修对应步骤。
