# L028练习与答案

1. **[基础·概念辨析]** 完成下面这项任务后，有同学的解释出现“质量单位未化kg”。任务：悬挂小重物观察重垂线，再在斜面图画重力。请指出应补充或改正的关键条件。

   **答案**：先按“重心处竖直向下”圈定研究对象和条件，再改正该判断；不能只写错误名称。
2. **[基础·读数/计算]** 2 kg物体重力约多少，取g=10 N/kg。

   **答案**：20 N，方向竖直向下。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 围绕“斜面重力图”，标出研究对象、关键方向或变量，并用图得出“重心处竖直向下”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·证据与实验]** 完成“悬挂小重物观察重垂线，再在斜面图画重力”时，写出要比较的对象、只改变或重点比较的条件，以及应记录的现象。

   **答案**：围绕“重心处竖直向下”完成一次清楚比较：先定对象和条件，再记录能支持或否定“重力是地球对物体的吸引”的现象；一次操作不能外推成普遍定律。
5. **[提升·解释论证]** 把下面的核心问题改成可检验的问题，并写出需要取得的证据：站在斜坡上，重力会沿斜坡向下吗？

   **答案**：先圈定对象和条件，再用“重心处竖直向下”连接证据与结论。如果出现“把竖直当垂直斜面”，订正这个判断步骤后，再用一道同类题确认。
