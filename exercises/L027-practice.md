# L027练习与答案

1. **概念判断**：用自己的话解释“力有大小、方向、作用点”。  
   **答案**：必须同时说出物理对象和关系：用带比例或标值箭头表示力。只重复标题不算完成。
2. **条件辨认**：不用公式，只用“用带比例或标值箭头表示力”判断并说明条件。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C6漏力值单位”。
3. **图示应用**：请画一张“规范力箭头图”，用图解释“用带比例或标值箭头表示力”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：画水平向右5 N的推力。  
   **答案**：箭头起于作用点、向右并标F=5 N。关键模型：用带比例或标值箭头表示力。
5. **情境与错因侦探**：同学完成“在门上不同位置推，画出作用点和方向”后出现“C3箭头起点错”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C3箭头起点错**。先检查与“用带比例或标值箭头表示力”直接相关的对象和条件，再决定重画图、重读数或重算。
