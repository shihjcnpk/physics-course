# L027练习与答案

1. **[基础·概念辨析]** 完成下面这项任务后，有同学的解释出现“漏力值单位”。任务：在门上不同位置推，画出作用点和方向。请指出应补充或改正的关键条件。

   **答案**：先按“用带比例或标值箭头表示力”圈定研究对象和条件，再改正该判断；不能只写错误名称。
2. **[基础·读数/计算]** 画水平向右5 N的推力。

   **答案**：箭头起于作用点、向右并标F=5 N。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 围绕“规范力箭头图”，标出研究对象、关键方向或变量，并用图得出“用带比例或标值箭头表示力”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·证据与实验]** 把例题信息整理成“对象—条件—关系—结论”四格，不增加题目没有给出的条件。

   **答案**：对象和条件必须来自题目；关系使用“用带比例或标值箭头表示力”；最后用单位或物理意义检查结论。
5. **[提升·解释论证]** 把下面的核心问题改成可检验的问题，并写出需要取得的证据：同样大小的力，为什么推门位置不同效果不同？

   **答案**：先圈定对象和条件，再用“用带比例或标值箭头表示力”连接证据与结论。如果出现“箭头起点错”，订正这个判断步骤后，再用一道同类题确认。
