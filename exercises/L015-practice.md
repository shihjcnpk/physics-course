# L015练习与答案

1. **[基础·概念辨析]** 三张带孔纸板只有在三个孔和光源大致共线时，末端光屏才见亮点。这支持什么结论？结论有什么条件？

   **答案**：支持光沿直线传播；条件是光在同种均匀介质中传播。
2. **[基础·读数/计算]** 影子怎样形成。

   **答案**：光沿直线传播，物体挡住部分光。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 画“三孔与影子光路图”：先画光在同一种均匀介质中的路径，再标出移动中间带孔纸板，最后在图旁写出看到的结果。

   **答案**：图中对象：光在同一种均匀介质中的路径；比较或变化：移动中间带孔纸板；结果：三孔共线时光才能通过；结论：光在同种均匀介质中沿直线传播，光线箭头表示传播方向。
4. **[典型·证据与实验]** 完成“让手电筒光通过三张带孔纸，移动中间纸”时，写出要比较的对象、只改变或重点比较的条件，以及应记录的现象。

   **答案**：围绕“用光线表示传播路径”完成一次清楚比较：先定对象和条件，再记录能支持或否定“光在同种均匀介质中沿直线传播”的现象；一次操作不能外推成普遍定律。
5. **[提升·解释论证]** 日食、影子和小孔成像都能用同一模型解释。写出共同模型和一个适用条件。

   **答案**：共同模型是光沿直线传播；适用条件是光在同种均匀介质中传播。
