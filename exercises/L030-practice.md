# L030练习与答案

1. **[基础·概念辨析]** 完成下面这项任务后，有同学的解释出现“同时改两个变量”。任务：只改变压力或粗糙程度，匀速拉木块记录力。请指出应补充或改正的关键条件。

   **答案**：先按“水平匀速时拉力等于摩擦力”圈定研究对象和条件，再改正该判断；不能只写错误名称。
2. **[基础·读数/计算]** 研究粗糙程度时什么必须相同。

   **答案**：压力等条件相同。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 围绕“水平匀速测摩擦图”，标出研究对象、关键方向或变量，并用图得出“水平匀速时拉力等于摩擦力”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·证据与实验]** 本课核心实验怎样保证结论可信？写出主动改变的量、观察测量的量和关键控制条件。

   **答案**：主动改变：压力或接触面粗糙程度，每次只改一个；观察测量：水平匀速时的拉力示数；关键控制：速度状态、接触面积处理和其余因素；证据记录：每个条件多次拉力及平均/代表值。
5. **[提升·解释论证]** 把下面的核心问题改成可检验的问题，并写出需要取得的证据：给箱子加重和铺毛巾，哪种更难拉？

   **答案**：先圈定对象和条件，再用“水平匀速时拉力等于摩擦力”连接证据与结论。如果出现“未利用平衡间接测量”，订正这个判断步骤后，再用一道同类题确认。
