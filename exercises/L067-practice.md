# L067练习与答案

1. **概念判断**：用自己的话解释“电流周围有磁场，螺线管外部像条形磁体”。  
   **答案**：必须同时说出物理对象和关系：电流方向决定磁场方向。只重复标题不算完成。
2. **条件辨认**：不用公式，只用“电流方向决定磁场方向”判断并说明条件。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C4只改电池位置不记录”。
3. **图示应用**：请画一张“螺线管小磁针图”，用图解释“电流方向决定磁场方向”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：电流反向后磁极怎样。  
   **答案**：N、S极对调。关键模型：电流方向决定磁场方向。
5. **情境与错因侦探**：同学完成“改变电流方向，记录两端小磁针N极指向”后出现“C3电流方向与场方向混淆”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C3电流方向与场方向混淆**。先检查与“电流方向决定磁场方向”直接相关的对象和条件，再决定重画图、重读数或重算。
