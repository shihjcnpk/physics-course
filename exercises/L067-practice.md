# L067练习与答案

1. **[基础·概念辨析]** 完成下面这项任务后，有同学的解释出现“只改电池位置不记录”。任务：改变电流方向，记录两端小磁针N极指向。请指出应补充或改正的关键条件。

   **答案**：先按“电流方向决定磁场方向”圈定研究对象和条件，再改正该判断；不能只写错误名称。
2. **[基础·读数/计算]** 电流反向后磁极怎样。

   **答案**：N、S极对调。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 围绕“螺线管小磁针图”，标出研究对象、关键方向或变量，并用图得出“电流方向决定磁场方向”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·证据与实验]** 本课核心实验怎样保证结论可信？写出主动改变的量、观察测量的量和关键控制条件。

   **答案**：主动改变：电流方向；观察测量：螺线管两端磁极方向；关键控制：线圈绕向、位置和小磁针初始状态；证据记录：电流方向与N/S极对应记录。
5. **[提升·解释论证]** 把下面的核心问题改成可检验的问题，并写出需要取得的证据：改变电流方向，螺线管磁极会变吗？

   **答案**：先圈定对象和条件，再用“电流方向决定磁场方向”连接证据与结论。如果出现“电流方向与场方向混淆”，订正这个判断步骤后，再用一道同类题确认。
