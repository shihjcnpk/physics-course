# L026练习与答案

1. **概念判断**：用自己的话解释“力是物体对物体的作用”。  
   **答案**：必须同时说出物理对象和关系：施力物—受力物成对分析。只重复标题不算完成。
2. **条件辨认**：不用公式，只用“施力物—受力物成对分析”判断并说明条件。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C2漏相互作用”。
3. **图示应用**：请画一张“相互作用对象图”，用图解释“施力物—受力物成对分析”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：脚踢球时谁受力。  
   **答案**：球受脚的力，脚也受球的力。关键模型：施力物—受力物成对分析。
5. **情境与错因侦探**：同学完成“挤气球、推墙，分别说出施力物和受力物”后出现“C1只说“有力”不说对象”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C1只说“有力”不说对象**。先检查与“施力物—受力物成对分析”直接相关的对象和条件，再决定重画图、重读数或重算。
