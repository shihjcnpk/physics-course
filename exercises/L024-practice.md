# L024练习与答案

1. **[基础·概念辨析]** 【2023北京中考第21题同型】土豆块质量44 g、体积40 cm³，求密度，并说明两数据为何必须属于同一块土豆。

   **答案**：密度1.1 g/cm³。同一对象的质量和体积才构成有意义的比值。
2. **[基础·读数/计算]** 石块54 g，水从30到50 mL，密度。

   **答案**：2.7 g/cm³。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 画“量筒排水图”：先画同一块不规则固体，再标出先称质量，再用排水法测体积，最后在图旁写出看到的结果。

   **答案**：图中对象：同一块不规则固体；比较或变化：先称质量，再用排水法测体积；结果：排开水的体积等于浸没固体体积；结论：同一物体的m与V必须配对，再用ρ=m/V计算密度。
4. **[典型·证据与实验]** 本课核心实验怎样保证结论可信？写出主动改变的量、观察测量的量和关键控制条件。

   **答案**：主动改变：测量类，无自变量；观察测量：同一固体的质量、体积和密度；关键控制：石块完全浸没且不吸水、量筒视线水平、质量体积对应同一物体；证据记录：石块质量、初末体积、体积差与密度。
5. **[提升·解释论证]** 先测体积后取出潮湿石块测质量，会使密度测量偏大还是偏小？说明证据链。

   **答案**：石块带水使测得质量偏大，而体积数据不变，ρ=m/V因此偏大。
