# L024练习与答案

1. **概念判断**：用自己的话解释“密度测量需配对同一物体的质量和体积”。  
   **答案**：必须同时说出物理对象和关系：天平测质量、排水测体积、计算密度。只重复标题不算完成。
2. **条件辨认**：写出ρ=m/V中各量对应的对象，并说一个不能直接使用它的情形。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C5体积差错”。
3. **图示应用**：请画一张“量筒排水图”，用图解释“天平测质量、排水测体积、计算密度”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：石块54 g，水从30到50 mL，密度。  
   **答案**：2.7 g/cm³。关键模型：天平测质量、排水测体积、计算密度。
5. **情境与错因侦探**：同学完成“测石块质量，再读放入前后水体积差；另测液体密度”后出现“C4质量体积非同一对象”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C4质量体积非同一对象**。先检查与“天平测质量、排水测体积、计算密度”直接相关的对象和条件，再决定重画图、重读数或重算。
