# L040练习与答案

1. **概念判断**：用自己的话解释“浮力等于排开流体所受重力”。  
   **答案**：必须同时说出物理对象和关系：排液质量→排液重力→浮力。只重复标题不算完成。
2. **条件辨认**：写出F浮=G排=ρ液gV排中各量对应的对象，并说一个不能直接使用它的情形。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C7用物体总体积代排液体积”。
3. **图示应用**：请画一张“溢水杯证据链图”，用图解释“排液质量→排液重力→浮力”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：排开0.2 kg水，取g=10，浮力。  
   **答案**：2 N。关键模型：排液质量→排液重力→浮力。
5. **情境与错因侦探**：同学完成“用溢水杯收集排水并比较其重与浮力”后出现“C6密度单位错”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C6密度单位错**。先检查与“排液质量→排液重力→浮力”直接相关的对象和条件，再决定重画图、重读数或重算。
