# L069练习与答案

1. **概念判断**：用自己的话解释“闭合电路一部分导体切割磁感线可产生感应电流”。  
   **答案**：必须同时说出物理对象和关系：机械运动—磁场变化—电能。只重复标题不算完成。
2. **条件辨认**：不用公式，只用“机械运动—磁场变化—电能”判断并说明条件。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C2与电动机能量链混淆”。
3. **图示应用**：请画一张“切割磁感线图”，用图解释“机械运动—磁场变化—电能”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：导体静止在磁场中是否有感应电流。  
   **答案**：没有；还需闭合且切割磁感线。关键模型：机械运动—磁场变化—电能。
5. **情境与错因侦探**：同学完成“改变导体运动方向、磁场方向与是否闭合，观察灵敏电流计”后出现“C4漏闭合条件”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C4漏闭合条件**。先检查与“机械运动—磁场变化—电能”直接相关的对象和条件，再决定重画图、重读数或重算。
