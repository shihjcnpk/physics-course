# L069练习与答案

1. **[基础·概念辨析]** 完成下面这项任务后，有同学的解释出现“与电动机能量链混淆”。任务：改变导体运动方向、磁场方向与是否闭合，观察灵敏电流计。请指出应补充或改正的关键条件。

   **答案**：先按“机械运动—磁场变化—电能”圈定研究对象和条件，再改正该判断；不能只写错误名称。
2. **[基础·读数/计算]** 导体静止在磁场中是否有感应电流。

   **答案**：没有；还需闭合且切割磁感线。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 围绕“切割磁感线图”，标出研究对象、关键方向或变量，并用图得出“机械运动—磁场变化—电能”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·证据与实验]** 本课核心实验怎样保证结论可信？写出主动改变的量、观察测量的量和关键控制条件。

   **答案**：主动改变：导体运动方向、磁场方向或电路通断，每轮只改一个；观察测量：灵敏电流计是否偏转及方向；关键控制：导体、磁体、运动速度范围和接线；证据记录：条件组合表和偏转结果。
5. **[提升·解释论证]** 把下面的核心问题改成可检验的问题，并写出需要取得的证据：没有电池，怎样让导线中出现电流？

   **答案**：先圈定对象和条件，再用“机械运动—磁场变化—电能”连接证据与结论。如果出现“漏闭合条件”，订正这个判断步骤后，再用一道同类题确认。
