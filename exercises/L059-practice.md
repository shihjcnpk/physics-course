# L059练习与答案

1. **[基础·概念辨析]** 完成下面这项任务后，有同学的解释出现“倒写关系”。任务：实测同一电阻的三组U、I；再分析教师提供的同电压、不同电阻数据。请指出应补充或改正的关键条件。

   **答案**：先按“控制变量建立I-U-R关系”圈定研究对象和条件，再改正该判断；不能只写错误名称。
2. **[基础·读数/计算]** 6 V加在3 Ω电阻上，电流。

   **答案**：2 A。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 围绕“I-U图像与电路图”，标出研究对象、关键方向或变量，并用图得出“控制变量建立I-U-R关系”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·证据与实验]** 本课核心实验怎样保证结论可信？写出主动改变的量、观察测量的量和关键控制条件。

   **答案**：主动改变：电压或电阻，每轮只改一个；观察测量：电流；关键控制：被要求保持不变的量、温度和电表量程；证据记录：I-U数据图与I-R比较表。
5. **[提升·解释论证]** 把下面的核心问题改成可检验的问题，并写出需要取得的证据：电流会怎样随电压和电阻改变？

   **答案**：先圈定对象和条件，再用“控制变量建立I-U-R关系”连接证据与结论。如果出现“控制量未保持”，订正这个判断步骤后，再用一道同类题确认。
