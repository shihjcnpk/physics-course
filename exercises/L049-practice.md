# L049练习与答案

1. **概念判断**：用自己的话解释“比热容表示单位质量升高1℃所需热量”。  
   **答案**：必须同时说出物理对象和关系：质量、温差、物质共同决定吸热。只重复标题不算完成。
2. **条件辨认**：写出Q=cmΔT中各量对应的对象，并说一个不能直接使用它的情形。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C6科学记数法错”。
3. **图示应用**：请画一张“水沙升温曲线图”，用图解释“质量、温差、物质共同决定吸热”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：2 kg水升高5℃，c=4.2×10³，吸热。  
   **答案**：4.2×10^4 J。关键模型：质量、温差、物质共同决定吸热。
5. **情境与错因侦探**：同学完成“等质量水和沙接受相同加热，比较升温”后出现“C5温差用末温”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C5温差用末温**。先检查与“质量、温差、物质共同决定吸热”直接相关的对象和条件，再决定重画图、重读数或重算。
