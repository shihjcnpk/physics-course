# L049练习与答案

1. **[基础·概念辨析]** 完成下面这项任务后，有同学的解释出现“科学记数法错”。任务：等质量水和沙接受相同加热，比较升温。请指出应补充或改正的关键条件。

   **答案**：先按“质量、温差、物质共同决定吸热”圈定研究对象和条件，再改正该判断；不能只写错误名称。
2. **[基础·读数/计算]** 2 kg水升高5℃，c=4.2×10³，吸热。

   **答案**：4.2×10^4 J。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 围绕“水沙升温曲线图”，标出研究对象、关键方向或变量，并用图得出“质量、温差、物质共同决定吸热”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·证据与实验]** 完成“等质量水和沙接受相同加热，比较升温”时，写出要比较的对象、只改变或重点比较的条件，以及应记录的现象。

   **答案**：围绕“质量、温差、物质共同决定吸热”完成一次清楚比较：先定对象和条件，再记录能支持或否定“比热容表示单位质量升高1℃所需热量”的现象；一次操作不能外推成普遍定律。
5. **[提升·解释论证]** 把下面的核心问题改成可检验的问题，并写出需要取得的证据：海边昼夜温差为什么比沙漠小？

   **答案**：先圈定对象和条件，再用“质量、温差、物质共同决定吸热”连接证据与结论。如果出现“温差用末温”，订正这个判断步骤后，再用一道同类题确认。
