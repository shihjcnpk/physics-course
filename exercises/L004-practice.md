# L004练习与答案

1. **概念判断**：用自己的话解释“平均速度对应一段总过程”。  
   **答案**：必须同时说出物理对象和关系：总路程除以总时间。只重复标题不算完成。
2. **条件辨认**：写出v平均=s总/t总中各量对应的对象，并说一个不能直接使用它的情形。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C7速度直接平均”。
3. **图示应用**：请画一张“分段时间轴”，用图解释“总路程除以总时间”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：前10 m用2 s、后10 m用3 s，整段平均速度。  
   **答案**：20/5=4 m/s，不能平均两个速度。关键模型：总路程除以总时间。
5. **情境与错因侦探**：同学完成“走快10 m再慢走10 m，记录各段和总时间”后出现“C2分段模型错”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C2分段模型错**。先检查与“总路程除以总时间”直接相关的对象和条件，再决定重画图、重读数或重算。
