# L013练习与答案

1. **概念判断**：用自己的话解释“蒸发可在任何温度发生，液化会放热”。  
   **答案**：必须同时说出物理对象和关系：液体↔气体的能量过程。只重复标题不算完成。
2. **条件辨认**：不用公式，只用“液体↔气体的能量过程”判断并说明条件。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C2水珠来源错”。
3. **图示应用**：请画一张“蒸发条件对比图”，用图解释“液体↔气体的能量过程”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：夏天冰饮料杯外水珠来自哪里。  
   **答案**：空气中水蒸气液化，不是杯内渗水。关键模型：液体↔气体的能量过程。
5. **情境与错因侦探**：同学完成“两滴等量水分别摊开与成滴，比较干燥速度”后出现“C1蒸发等同沸腾”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C1蒸发等同沸腾**。先检查与“液体↔气体的能量过程”直接相关的对象和条件，再决定重画图、重读数或重算。
