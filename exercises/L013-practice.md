# L013练习与答案

1. **[基础·概念辨析]** 冰饮料杯外壁出现水珠。水珠来自杯内渗水还是空气？写出证据方向。

   **答案**：来自空气中的水蒸气液化；可用密封不漏水的冷杯仍出现外壁水珠作证据。
2. **[基础·读数/计算]** 夏天冰饮料杯外水珠来自哪里。

   **答案**：空气中水蒸气液化，不是杯内渗水。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 画“蒸发条件对比图”：先画液态水与水蒸气，再标出改变温度、表面积或空气流动，最后在图旁写出看到的结果。

   **答案**：图中对象：液态水与水蒸气；比较或变化：改变温度、表面积或空气流动；结果：蒸发快慢变化；水蒸气遇冷成小水滴；结论：汽化吸热，液化放热；白雾是小液滴，不是水蒸气。
4. **[典型·证据与实验]** 完成“两滴等量水分别摊开与成滴，比较干燥速度”时，写出要比较的对象、只改变或重点比较的条件，以及应记录的现象。

   **答案**：围绕“液体↔气体的能量过程”完成一次清楚比较：先定对象和条件，再记录能支持或否定“蒸发可在任何温度发生，液化会放热”的现象；一次操作不能外推成普遍定律。
5. **[提升·解释论证]** 等量水滴一滴摊开、一滴保持水滴状，如何控制变量并判断蒸发快慢？

   **答案**：水量、温度、空气流动和材料相同，只改表面积；比较相同时间剩余水量或完全蒸干时间。
