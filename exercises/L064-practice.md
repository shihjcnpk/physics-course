# L064｜焦耳定律：电流为什么发热｜10分钟练习

1. **[基础·北京题型：概念辨析]** 在“串联两不同电阻丝，用相同电流比较温升”中，有同学出现了“串并联时没辨相同量”。这个结论可靠吗？

   **答案**：不可靠。应先按“控制变量比较电阻丝产热”核对研究对象和条件。
2. **[基础·北京题型：读数/计算]** 电流变2倍，其他不变，电热变几倍。

   **答案**：4倍。关键条件：对象、过程和单位必须配对。
3. **[典型·北京题型：读图作图]** 围绕“串联电热对比图”，标出研究对象、关键方向或变量，并用图得出“控制变量比较电阻丝产热”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·北京题型：实验探究]** 要完成“串联两不同电阻丝，用相同电流比较温升”，写出本次只改变或重点比较的量，以及判断结论所需的证据。

   **答案**：围绕“控制变量比较电阻丝产热”只改变一个关键因素，其他条件保持一致；至少取得可比较的数据或清楚现象，不能由一次偶然结果下结论。
5. **[提升·北京题型：解释/论证]** 把“电炉丝很热，连接导线为什么不该同样热？”改成可检验的问题，并写出需要取得的证据。

   **答案**：先圈定对象和条件，再用“控制变量比较电阻丝产热”连接证据与结论。如果出现“漏平方”，订正这个判断步骤后，再用一道同类题确认。
