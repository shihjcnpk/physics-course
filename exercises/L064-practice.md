# L064练习与答案

1. **[基础·概念辨析]** 完成下面这项任务后，有同学的解释出现“串并联时没辨相同量”。任务：串联两不同电阻丝，用相同电流比较温升。请指出应补充或改正的关键条件。

   **答案**：先按“控制变量比较电阻丝产热”圈定研究对象和条件，再改正该判断；不能只写错误名称。
2. **[基础·读数/计算]** 电流变2倍，其他不变，电热变几倍。

   **答案**：4倍。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 围绕“串联电热对比图”，标出研究对象、关键方向或变量，并用图得出“控制变量比较电阻丝产热”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·证据与实验]** 完成“串联两不同电阻丝，用相同电流比较温升”时，写出要比较的对象、只改变或重点比较的条件，以及应记录的现象。

   **答案**：围绕“控制变量比较电阻丝产热”完成一次清楚比较：先定对象和条件，再记录能支持或否定“电热与电流平方、电阻、时间有关”的现象；一次操作不能外推成普遍定律。
5. **[提升·解释论证]** 把下面的核心问题改成可检验的问题，并写出需要取得的证据：电炉丝很热，连接导线为什么不该同样热？

   **答案**：先圈定对象和条件，再用“控制变量比较电阻丝产热”连接证据与结论。如果出现“漏平方”，订正这个判断步骤后，再用一道同类题确认。
