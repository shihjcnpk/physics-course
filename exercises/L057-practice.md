# L057练习与答案

1. **[基础·概念辨析]** 完成下面这项任务后，有同学的解释出现“把电流规律套给电压”。任务：分别测电源、各灯两端电压并换灯复测。请指出应补充或改正的关键条件。

   **答案**：先按“回路电压分配模型”圈定研究对象和条件，再改正该判断；不能只写错误名称。
2. **[基础·读数/计算]** 串联两灯1.2 V、1.8 V，电源电压。

   **答案**：3.0 V。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 围绕“串并联电压图”，标出研究对象、关键方向或变量，并用图得出“回路电压分配模型”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·证据与实验]** 本课核心实验怎样保证结论可信？写出主动改变的量、观察测量的量和关键控制条件。

   **答案**：主动改变：测量元件或支路；观察测量：各部分两端电压；关键控制：电源、元件组合、量程和连接方式；证据记录：串联总分电压与并联支路电压多组数据。
5. **[提升·解释论证]** 把下面的核心问题改成可检验的问题，并写出需要取得的证据：两只串联灯怎样“分”电压？

   **答案**：先圈定对象和条件，再用“回路电压分配模型”连接证据与结论。如果出现“测量端点错”，订正这个判断步骤后，再用一道同类题确认。
