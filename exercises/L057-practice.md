# L057练习与答案

1. **概念判断**：用自己的话解释“串联总电压等于各部分之和，并联各支路电压相等”。  
   **答案**：必须同时说出物理对象和关系：回路电压分配模型。只重复标题不算完成。
2. **条件辨认**：写出U总=U1+U2；U=U1=U2中各量对应的对象，并说一个不能直接使用它的情形。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C4把电流规律套给电压”。
3. **图示应用**：请画一张“串并联电压图”，用图解释“回路电压分配模型”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：串联两灯1.2 V、1.8 V，电源电压。  
   **答案**：3.0 V。关键模型：回路电压分配模型。
5. **情境与错因侦探**：同学完成“分别测电源、各灯两端电压并换灯复测”后出现“C3测量端点错”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C3测量端点错**。先检查与“回路电压分配模型”直接相关的对象和条件，再决定重画图、重读数或重算。
