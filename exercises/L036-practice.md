# L036练习与答案

1. **[基础·概念辨析]** 完成下面这项任务后，有同学的解释出现“漏压强差”。任务：用装水杯和纸片倒置，观察纸片不落。请指出应补充或改正的关键条件。

   **答案**：先按“内外压强差产生效果”圈定研究对象和条件，再改正该判断；不能只写错误名称。
2. **[基础·读数/计算]** 吸管吸饮料是谁把液体压上来。

   **答案**：大气压把液体压入低压的吸管。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 围绕“吸盘压强差图”，标出研究对象、关键方向或变量，并用图得出“内外压强差产生效果”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·证据与实验]** 完成“用装水杯和纸片倒置，观察纸片不落”时，写出要比较的对象、只改变或重点比较的条件，以及应记录的现象。

   **答案**：围绕“内外压强差产生效果”完成一次清楚比较：先定对象和条件，再记录能支持或否定“大气有压强且向各方向作用”的现象；一次操作不能外推成普遍定律。
5. **[提升·解释论证]** 把下面的核心问题改成可检验的问题，并写出需要取得的证据：吸盘为什么能贴在墙上？

   **答案**：先圈定对象和条件，再用“内外压强差产生效果”连接证据与结论。如果出现“说嘴把水“吸上来””，订正这个判断步骤后，再用一道同类题确认。
