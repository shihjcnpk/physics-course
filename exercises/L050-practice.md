# L050练习与答案

1. **[基础·概念辨析]** 完成下面这项任务后，有同学的解释出现“把热值随质量改变”。任务：比较资料中同质量不同燃料完全燃烧的放热量并画能量链。请指出应补充或改正的关键条件。

   **答案**：先按“燃料质量与完全燃烧放热的比例模型”圈定研究对象和条件，再改正该判断；不能只写错误名称。
2. **[基础·读数/计算]** 0.1 kg燃料热值3×10^7 J/kg，完全燃烧放热。

   **答案**：3×10^6 J。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 围绕“燃料能量流图”，标出研究对象、关键方向或变量，并用图得出“燃料质量与完全燃烧放热的比例模型”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·证据与实验]** 完成“比较资料中同质量不同燃料完全燃烧的放热量并画能量链”时，写出要比较的对象、只改变或重点比较的条件，以及应记录的现象。

   **答案**：围绕“燃料质量与完全燃烧放热的比例模型”完成一次清楚比较：先定对象和条件，再记录能支持或否定“热值描述单位质量燃料完全燃烧时放出的热量”的现象；一次操作不能外推成普遍定律。
5. **[提升·解释论证]** 把下面的核心问题改成可检验的问题，并写出需要取得的证据：同质量木柴和天然气为什么放热不同？

   **答案**：先圈定对象和条件，再用“燃料质量与完全燃烧放热的比例模型”连接证据与结论。如果出现“漏完全燃烧条件”，订正这个判断步骤后，再用一道同类题确认。
