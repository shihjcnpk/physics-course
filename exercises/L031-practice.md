# L031练习与答案

1. **概念判断**：用自己的话解释“力不是维持运动的原因”。  
   **答案**：必须同时说出物理对象和关系：阻力逐渐减小→运动保持更久→理想无阻力。只重复标题不算完成。
2. **条件辨认**：不用公式，只用“阻力逐渐减小→运动保持更久→理想无阻力”判断并说明条件。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C2实验结论直接等同无阻力”。
3. **图示应用**：请画一张“斜面小车推理图”，用图解释“阻力逐渐减小→运动保持更久→理想无阻力”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：运动物体不受力将怎样。  
   **答案**：保持匀速直线运动。关键模型：阻力逐渐减小→运动保持更久→理想无阻力。
5. **情境与错因侦探**：同学完成“比较毛巾、木板、玻璃面上小车滑行距离并外推”后出现“C1把力当维持运动”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C1把力当维持运动**。先检查与“阻力逐渐减小→运动保持更久→理想无阻力”直接相关的对象和条件，再决定重画图、重读数或重算。
