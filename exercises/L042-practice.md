# L042练习与答案

1. **概念判断**：用自己的话解释“功需要力且物体沿力方向移动距离”。  
   **答案**：必须同时说出物理对象和关系：力与力方向距离的乘积。只重复标题不算完成。
2. **条件辨认**：写出W=Fs中各量对应的对象，并说一个不能直接使用它的情形。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C7有力就判做功”。
3. **图示应用**：请画一张“力与位移夹向图”，用图解释“力与力方向距离的乘积”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：10 N水平推物前进3 m，做功。  
   **答案**：30 J。关键模型：力与力方向距离的乘积。
5. **情境与错因侦探**：同学完成“对比推车前进、提物静止、提物水平走”后出现“C4漏力方向”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C4漏力方向**。先检查与“力与力方向距离的乘积”直接相关的对象和条件，再决定重画图、重读数或重算。
