# L037练习与答案

1. **概念判断**：用自己的话解释“在常见稳定流动比较中，流速较大处压强较小”。  
   **答案**：必须同时说出物理对象和关系：两侧流速差→压强差→受力。只重复标题不算完成。
2. **条件辨认**：不用公式，只用“两侧流速差→压强差→受力”判断并说明条件。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C3压强箭头反”。
3. **图示应用**：请画一张“机翼流线图”，用图解释“两侧流速差→压强差→受力”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：火车站安全线为什么要退后。  
   **答案**：列车旁空气流速较大、压强较小，外侧压强可能把人推近。关键模型：两侧流速差→压强差→受力。
5. **情境与错因侦探**：同学完成“平行悬挂两纸条，从中间吹气并预测”后出现“C1说气流把纸吹开”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C1说气流把纸吹开**。先检查与“两侧流速差→压强差→受力”直接相关的对象和条件，再决定重画图、重读数或重算。
