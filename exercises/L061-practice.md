# L061练习与答案

1. **概念判断**：用自己的话解释“由同一状态的U和I间接求R”。  
   **答案**：必须同时说出物理对象和关系：电流表串联、电压表并联、变阻器保护。只重复标题不算完成。
2. **条件辨认**：写出R=U/I中各量对应的对象，并说一个不能直接使用它的情形。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C9闭合前未调最大”。
3. **图示应用**：请画一张“伏安法电路图”，用图解释“电流表串联、电压表并联、变阻器保护”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：2.4 V、0.3 A，电阻。  
   **答案**：8 Ω。关键模型：电流表串联、电压表并联、变阻器保护。
5. **情境与错因侦探**：同学完成“先最大电阻保护，再测三组U、I并分析”后出现“C4电表数据非同一时刻”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C4电表数据非同一时刻**。先检查与“电流表串联、电压表并联、变阻器保护”直接相关的对象和条件，再决定重画图、重读数或重算。
