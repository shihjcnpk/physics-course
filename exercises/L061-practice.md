# L061练习与答案

1. **[基础·概念辨析]** 完成下面这项任务后，有同学的解释出现“闭合前未调最大”。任务：先最大电阻保护，再测三组U、I并分析。请指出应补充或改正的关键条件。

   **答案**：先按“电流表串联、电压表并联、变阻器保护”圈定研究对象和条件，再改正该判断；不能只写错误名称。
2. **[基础·读数/计算]** 2.4 V、0.3 A，电阻。

   **答案**：8 Ω。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 围绕“伏安法电路图”，标出研究对象、关键方向或变量，并用图得出“电流表串联、电压表并联、变阻器保护”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·证据与实验]** 本课核心实验怎样保证结论可信？写出主动改变的量、观察测量的量和关键控制条件。

   **答案**：主动改变：滑动变阻器造成的工作状态；观察测量：同一时刻U、I及算得R；关键控制：待测电阻、接线、量程和闭合前最大阻值；证据记录：不少于三组U、I、R及异常值分析。
5. **[提升·解释论证]** 把下面的核心问题改成可检验的问题，并写出需要取得的证据：未知电阻怎样用两个表测出来？

   **答案**：先圈定对象和条件，再用“电流表串联、电压表并联、变阻器保护”连接证据与结论。如果出现“电表数据非同一时刻”，订正这个判断步骤后，再用一道同类题确认。
