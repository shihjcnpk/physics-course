# L045练习与答案

1. **[基础·概念辨析]** 完成下面这项任务后，有同学的解释出现“比例求解错”。任务：改变钩码位置与数量，记录平衡时力和力臂。请指出应补充或改正的关键条件。

   **答案**：先按“力×力臂两侧平衡”圈定研究对象和条件，再改正该判断；不能只写错误名称。
2. **[基础·读数/计算]** 阻力20 N、阻力臂0.1 m，动力臂0.5 m。

   **答案**：动力4 N。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 围绕“杠杆五要素图”，标出研究对象、关键方向或变量，并用图得出“力×力臂两侧平衡”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·证据与实验]** 本课核心实验怎样保证结论可信？写出主动改变的量、观察测量的量和关键控制条件。

   **答案**：主动改变：力或力臂；观察测量：杠杆平衡时另一侧的力或力臂；关键控制：杠杆水平、支点、钩码规格和读力方向；证据记录：多组F1、l1、F2、l2乘积。
5. **[提升·解释论证]** 把下面的核心问题改成可检验的问题，并写出需要取得的证据：为什么用长扳手更省力？

   **答案**：先圈定对象和条件，再用“力×力臂两侧平衡”连接证据与结论。如果出现“力臂画成杆长”，订正这个判断步骤后，再用一道同类题确认。
