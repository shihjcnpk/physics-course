# L045练习与答案

1. **概念判断**：用自己的话解释“绕固定点转动的硬棒可抽象为杠杆”。  
   **答案**：必须同时说出物理对象和关系：力×力臂两侧平衡。只重复标题不算完成。
2. **条件辨认**：写出F1l1=F2l2中各量对应的对象，并说一个不能直接使用它的情形。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C5比例求解错”。
3. **图示应用**：请画一张“杠杆五要素图”，用图解释“力×力臂两侧平衡”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：阻力20 N、阻力臂0.1 m，动力臂0.5 m。  
   **答案**：动力4 N。关键模型：力×力臂两侧平衡。
5. **情境与错因侦探**：同学完成“改变钩码位置与数量，记录平衡时力和力臂”后出现“C3力臂画成杆长”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C3力臂画成杆长**。先检查与“力×力臂两侧平衡”直接相关的对象和条件，再决定重画图、重读数或重算。
