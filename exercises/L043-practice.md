# L043练习与答案

1. **[基础·概念辨析]** 完成下面这项任务后，有同学的解释出现“瓦特单位错”。任务：记录走与快走同一楼梯的时间，比较功率。请指出应补充或改正的关键条件。

   **答案**：先按“功与时间的比率”圈定研究对象和条件，再改正该判断；不能只写错误名称。
2. **[基础·读数/计算]** 做600 J功用3 s，功率。

   **答案**：200 W。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 围绕“爬楼功时间图”，标出研究对象、关键方向或变量，并用图得出“功与时间的比率”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·证据与实验]** 完成“记录走与快走同一楼梯的时间，比较功率”时，写出要比较的对象、只改变或重点比较的条件，以及应记录的现象。

   **答案**：围绕“功与时间的比率”完成一次清楚比较：先定对象和条件，再记录能支持或否定“功率表示单位时间做功”的现象；一次操作不能外推成普遍定律。
5. **[提升·解释论证]** 把下面的核心问题改成可检验的问题，并写出需要取得的证据：同样爬楼，跑上去和走上去哪里不同？

   **答案**：先圈定对象和条件，再用“功与时间的比率”连接证据与结论。如果出现“功多等同功率大”，订正这个判断步骤后，再用一道同类题确认。
