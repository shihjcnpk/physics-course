# 新课标人教版初中物理核心课程

70节短课，严格执行“20分钟正课+10分钟练习”和“1个核心概念+1个核心模型/规律+1种典型应用”。

在线访问：https://shihjcnpk.github.io/physics-course/#/

## 八上漫画图解

八年级上册 L001—L025 已加入与数学课程一致的“通俗类比 → 分阶段图示 → 四步读图链 → 正式表述”结构。每课都明确标出“看谁—改什么/比什么—看到什么—所以什么”，并包含原创轻漫画三格、比喻边界和记忆钩子；反射、折射、透镜、声波、物态变化与密度等关键抽象内容另有科学模型 SVG。

课后练习按近五年北京中考的稳定题型重排为“概念辨析—读数/计算—读图作图—实验探究—解释论证”，八上精选题标注对应真题年份或同型来源。原题只在与当前单课目标完全匹配时使用。

设计说明见 [GRADE8_VISUAL_EXPLAINERS.md](GRADE8_VISUAL_EXPLAINERS.md)。

## 使用顺序

1. 从[课程总表](COURSE_MAP.md)进入一节课。
2. 若要跟学校同步，从[按课本章节学习](TEXTBOOK_CHAPTERS.md)选择册次、章和节，再点击对应课程。
3. 先做预测，再看实验或证据；不要提前翻答案。
4. 20分钟后停止输入，完成5题练习。
5. 只记录主要错因；课程页面直接写“哪里错、下一步怎么改”，不向孩子展示内部代码。
6. 每课开始先看“数学准备”；不稳就先做5分钟小补丁，完成后再进入物理钩子。

## 目录

- `lessons/`：70节完整课程正文。
- `exercises/`：可独立打印的练习与答案。
- `data/`：课程、课标和三层知识图谱单一事实源。
- `TEXTBOOK_CHAPTERS.md`：按八上、八下、九年级全一册逐节进入对应课程的第二导航。
- `assets/`：可复用的科学示意图与动画说明。
- `validation/`：自动审计与人工抽查。
- `sources/`：官方来源记录，不复制教材全文。
- `sources/BEIJING_ZHONGKAO_PRACTICE_BENCHMARK.md`：近五年北京中考物理练习设计基准与来源。

## 错因记录

数据文件保留错因分类，便于后续统计和安排复习；孩子看到的课程正文只使用“概念没理解、模型没选对、图没画对、漏看条件、计算错误、单位错误、关系用错、检查遗漏、做题中途漏条件”等直白表述。
