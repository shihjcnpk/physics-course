# 新课标人教版初中物理核心课程

70节短课，严格执行“20分钟正课+10分钟练习”和“1个核心概念+1个核心模型/规律+1种典型应用”。

在线访问：https://shihjcnpk.github.io/physics-course/#/

## 使用顺序

1. 从[课程总表](COURSE_MAP.md)进入一节课。
2. 若要跟学校同步，从[按课本章节学习](TEXTBOOK_CHAPTERS.md)选择册次、章和节，再点击对应课程。
3. 先做预测，再看实验或证据；不要提前翻答案。
4. 20分钟后停止输入，完成5题练习。
5. 只记录主要错因C1～C9，并按D0/D1/D3/D7/D14复习。
6. 数学前置不稳时使用该课末尾5分钟数学小补丁。

## 目录

- `lessons/`：70节完整课程正文。
- `exercises/`：可独立打印的练习与答案。
- `data/`：课程、课标和三层知识图谱单一事实源。
- `TEXTBOOK_CHAPTERS.md`：按八上、八下、九年级全一册逐节进入对应课程的第二导航。
- `assets/`：可复用的科学示意图与动画说明。
- `validation/`：自动审计与人工抽查。
- `sources/`：官方来源记录，不复制教材全文。

## 错因代码

C1概念、C2模型、C3图示、C4条件提取、C5数学、C6单位、C7公式、C8粗心、C9注意丢失。
