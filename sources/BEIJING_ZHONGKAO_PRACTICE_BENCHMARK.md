# 近五年北京中考物理练习设计基准

核验日期：2026-08-17。参考窗口：2021—2025年北京中考物理试题、答案及考试评价。

## 使用原则

1. 允许精选真题原题，但必须标注年份与题号；不整卷搬运，不改变原题结论。
2. 只在题目与当前单课目标、已学前置完全匹配时使用原题；跨模块综合题后置。
3. 每课仍限定5题、约10分钟：2道基础、2道典型、1道提升。
4. “中考难度”指任务形态、信息提取和证据推理达到北京卷要求，不是每题都做压轴题。
5. 配图题必须让图本身标明研究对象、变量、结果与结论，不能仅靠装饰性画面猜题意。

## 五类稳定任务

| 课程练习位 | 北京卷常见任务 | 本课程用途 |
|---|---|---|
| 基础1 | 概念辨析、生活现象选择 | 检查概念边界，不背句子 |
| 基础2 | 仪表读数、单位换算、一步计算 | 检查基本工具与数量关系 |
| 典型1 | 读图、作图、图像或表格信息 | 从视觉证据得到结论 |
| 典型2 | 实验操作、控制变量、数据归纳 | 检查科学探究链 |
| 提升1 | 解释、论证、开放应用 | 用模型连接证据与结论 |

## 近五年样本带来的具体约束

- 2021、2022卷保持单项选择、多项选择、实验探究、科普阅读和计算等多样任务；课程只抽取与单课匹配的小任务。
- 2022卷出现传统乐器声音辨析、物态变化图、密度测量、光学与力学生活情境，强调概念必须落到图和真实对象。
- 2023卷用自制温度计、土豆密度、液体压强、凸透镜数据表与科技阅读等情境，强调实验经历、表格归纳和解决实际问题。
- 2024卷以自行车、火箭、光现象等真实情境考查基础模型，题干短但要求准确识别对象和条件。
- 2025卷继续保持70分、70分钟、26题的笔试结构，并增加实验操作评价；试题评价强调基础性、应用性、探究性、综合性和开放创新。
