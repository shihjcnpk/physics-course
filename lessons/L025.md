# 第25课：核心实验：测液体密度

## 今天只学一件事

回答：**液体不能直接放在天平上，怎样得到同一份液体的质量和体积？**

## 开课前｜数学准备

数学前置：减法、体积差、小数。本课数学只服务于物理问题“液体不能直接放在天平上，怎样得到同一份液体的质量和体积？”。减法：从总量中扣除容器或初始部分；体积差：用末读数减初读数得到排开或取用体积；小数：准确记录和比较测量值。

**数学小补丁**：若不稳定，先做5分钟补丁：用一个生活数例复习减法、体积差、小数，只练本课会用到的一步。

## 为什么要学它？

想一想这个生活场景：先测空烧杯质量，再加入液体测总质量，最后把液体倒入量筒读体积。

## 先猜并设计

把答案先写成一句话：结果会怎样？你依据的是“看起来”，还是一个可检查的条件？先保留答案，不马上判对错。

## 操作与取证

任务：先测空烧杯质量，再加入液体测总质量，最后把液体倒入量筒读体积。

1. 指出研究对象。
2. 圈出改变的量和保持不变的量。
3. 记录一个现象或一组数据。
4. 立刻说一句：“我看到的证据是……”。

先写自变量、因变量和至少两个控制量；按安全规范完成操作，至少取得三组有效数据。若课堂器材未就绪，使用教师提供的同结构数据做分析，本实验仍需另行完成实操。

### 核心实验设计卡

- 自变量/主动改变：测量类，无自变量。
- 因变量/观察测量：同一份液体的质量、体积和密度。
- 关键控制与规范：天平调平、容器质量正确相减、量筒视线水平并减少残留。
- 证据记录：空容器质量、总质量、液体体积与密度。
- 结论规则：先描述数据共同趋势，再回答问题；异常数据不许静默删除，要复测或说明。


安全提示：使用小型、稳定、无尖锐边缘的器材；发现器材异常立即停止。 `CORE`实验应在教师或成人指导下完成。

## 你发现了什么？

现象支持的最短结论是：**测液体密度要用容器质量差得到液体质量，并与量筒体积配对**。若证据不足，只写“目前支持”，不要把猜想当结论。

## 整理证据，建立模型

画：**液体密度测量流程图**。图上只保留对象、关键方向/变量和边界。

模型句：**容器与液体总质量−容器质量→液体质量，再除以体积**。

## 正式物理知识

- 概念：测液体密度要用容器质量差得到液体质量，并与量筒体积配对。
- 关系：ρ=(m总-m容)/V
- 为什么需要：用一个数量关系回答“液体不能直接放在天平上，怎样得到同一份液体的质量和体积？”。
- 量与单位：m总和m容用同一质量单位；V是同一份液体的体积。
- 怎样变化：先用质量差得到液体质量，再除以体积。
- 适用边界：质量差与量筒体积必须对应同一份液体；倒液残留会带来误差。

**材料与尺度阅读卡（不占本课20分钟）**：材料选择要把使用条件与导热、强度、安全等属性配对；再用数量级轴从宇宙—地球—人—细胞—分子—原子—原子核排序。这里只建立材料证据和尺度感，不增加计算。

## 一个典型例题

**题目**：空杯40 g，杯和液体共94 g，液体体积60 cm³，密度？

**六步建模**：对象是谁 → 已知什么 → 求什么 → 画最简图 → 选“容器与液体总质量−容器质量→液体质量，再除以体积” → 检查单位和意义。

**答案**：0.90 g/cm³。

## 一句话收束

今天记住：**测液体密度要用容器质量差得到液体质量，并与量筒体积配对；容器与液体总质量−容器质量→液体质量，再除以体积。**

## 10分钟练习

1. **[基础·概念辨析]** 测液体密度时，小京把烧杯和液体的总质量94 g直接除以液体体积60 cm³。这样做对吗？

   **答案**：不对。94 g中包含烧杯质量，必须先减去空烧杯质量，再用液体质量除以同一份液体的体积。
2. **[基础·读数/计算]** 空杯40 g，杯和液体共94 g，液体体积60 cm³，密度。

   **答案**：0.90 g/cm³。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 画“液体密度测量流程图”：先画同一份液体、容器和量筒，再标出先减去容器质量，再读取对应液体体积，最后在图旁写出看到的结果。

   **答案**：图中对象：同一份液体、容器和量筒；比较或变化：先减去容器质量，再读取对应液体体积；结果：得到液体质量和体积这一对数据；结论：用ρ=(m总-m容)/V计算液体密度，质量和体积必须对应同一份液体。
4. **[典型·证据与实验]** 本课核心实验怎样保证结论可信？写出主动改变的量、观察测量的量和关键控制条件。

   **答案**：主动改变：测量类，无自变量；观察测量：同一份液体的质量、体积和密度；关键控制：天平调平、容器质量正确相减、量筒视线水平并减少残留；证据记录：空容器质量、总质量、液体体积与密度。
5. **[提升·解释论证]** 若先量出60 cm³液体，再把液体倒入烧杯称质量，量筒中有少量液体残留，测得密度偏大还是偏小？

   **答案**：倒入烧杯的液体质量对应的实际体积小于记录的60 cm³，却仍用60 cm³作分母，因此测得密度偏小。

## 为什么错

- **忘记减容器质量**：物理关系不变，只把计算过程单独重算一遍。
- **质量与体积不是同一份液体**：重读题目，只圈出决定答案的条件，再作答。
- **做题中途漏条件**：在题目旁画“对象—条件—单位”三格，完成一格勾一格。
