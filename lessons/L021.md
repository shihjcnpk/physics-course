# 第21课：凸透镜应用与眼睛

## 今天只学一件事

回答：**照相机、投影仪、放大镜为什么都用凸透镜？**

## 0～2分钟｜为什么要学它？

先不要找公式。想象这个生活场景：用凸透镜分别看近字和远景，比较能否在纸上接像。本课只追一个变化，不追所有细节。

## 2～5分钟｜先猜一猜

把答案先写成一句话：结果会怎样？你依据的是“看起来”，还是一个可检查的条件？先保留答案，不马上判对错。

## 5～10分钟｜看现象 / 做实验

任务：用凸透镜分别看近字和远景，比较能否在纸上接像。

1. 指出研究对象。
2. 圈出改变的量和保持不变的量。
3. 记录一个现象或一组数据。
4. 立刻说一句：“我看到的证据是……”。

只改变本课研究的一个因素，取得一个清楚现象或一组可比较数据。



安全提示：不用太阳作光源，不通过透镜直视太阳；优先使用低温LED光源。

## 你发现了什么？

现象支持的最短结论是：**不同物距区间对应不同应用**。若证据不足，只写“目前支持”，不要把猜想当结论。

## 10～14分钟｜把现象画出来，建立模型

画：**三种应用对比图**。图上只保留对象、关键方向/变量和边界。

模型句：**成像区间→器件功能**。

## 14～17分钟｜正式物理知识

- 概念：不同物距区间对应不同应用。
- 关系：本课无须背公式，先稳定概念和图。
- 本课不用计算公式。模型边界：成像区间→器件功能。
- 先用图和证据判断，不把一句口诀套到所有情境。

**课后教材融合卡（不占本课20分钟）**：用两个凸透镜制作简易望远镜时只观察远处非太阳目标，并用透镜成像模型解释两片透镜的分工。

## 17～19分钟｜一个典型例题

**题目**：近视眼用什么透镜矫正？

**六步建模**：对象是谁 → 已知什么 → 求什么 → 画最简图 → 选“成像区间→器件功能” → 检查单位和意义。

**答案**：凹透镜，使光先发散再进入眼睛。

## 19～20分钟｜一句话收束

今天记住：**不同物距区间对应不同应用；成像区间→器件功能。**

## 10分钟练习

1. **概念判断**：用自己的话解释“不同物距区间对应不同应用”。  
   **答案**：必须同时说出物理对象和关系：成像区间→器件功能。只重复标题不算完成。
2. **条件辨认**：不用公式，只用“成像区间→器件功能”判断并说明条件。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C1虚像可接屏”。
3. **图示应用**：请画一张“三种应用对比图”，用图解释“成像区间→器件功能”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：近视眼用什么透镜矫正。  
   **答案**：凹透镜，使光先发散再进入眼睛。关键模型：成像区间→器件功能。
5. **情境与错因侦探**：同学完成“用凸透镜分别看近字和远景，比较能否在纸上接像”后出现“C2器件区间混淆”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C2器件区间混淆**。先检查与“成像区间→器件功能”直接相关的对象和条件，再决定重画图、重读数或重算。

## 为什么错

- C2器件区间混淆：回到本课模型卡，重新指出对象和关键条件。
- C1虚像可接屏：只修这一步，再做第4题；不要整课重听。
- 若是C9注意丢失：在题目旁画“对象—条件—单位”三格，完成一格勾一格。
