# 第65课：家庭电路与安全用电

## 今天只学一件事

回答：**保险装置为什么装在火线上？**

## 开课前｜数学准备

数学前置：估算。本课数学只服务于物理问题“保险装置为什么装在火线上？”。估算：先判断结果数量级是否合理。

**数学小补丁**：若不稳定，先做5分钟补丁：用一个生活数例复习估算，只练本课会用到的一步。

## 为什么要学它？

想一想这个生活场景：识别三孔插座、总开关和漏电保护器，不接触市电。

## 先猜一猜

把答案先写成一句话：结果会怎样？你依据的是“看起来”，还是一个可检查的条件？先保留答案，不马上判对错。

## 看现象 / 做实验

任务：识别三孔插座、总开关和漏电保护器，不接触市电。

1. 指出研究对象。
2. 圈出改变的量和保持不变的量。
3. 记录一个现象或一组数据。
4. 立刻说一句：“我看到的证据是……”。

只改变本课研究的一个因素，取得一个清楚现象或一组可比较数据。



安全提示：只观察断电模型、图片或演示板；不拆插座，不触碰或改接家庭市电线路。

## 你发现了什么？

现象支持的最短结论是：**家庭电路并联，保护装置切断危险通路**。若证据不足，只写“目前支持”，不要把猜想当结论。

## 把现象画出来，建立模型

画：**家庭电路安全图**。图上只保留对象、关键方向/变量和边界。

模型句：**火线—用电器—零线与接地保护**。

## 正式物理知识

- 概念：家庭电路并联，保护装置切断危险通路。
- 关系：本课无须背公式，先稳定概念和图。
- 本课不用计算公式。模型边界：家庭电路结论用于规范交流低压供电系统；学习时只操作断电模型，不接触市电。
- 先用图和证据判断，不把一句口诀套到所有情境。

**课后教材融合卡（不占本课20分钟）**：只在断电模型图上设计家庭电路，说明并联、总开关、保护装置和接地的作用，禁止改接真实线路。

## 一个典型例题

**题目**：多个大功率电器同插座有何风险？

**六步建模**：对象是谁 → 已知什么 → 求什么 → 画最简图 → 选“火线—用电器—零线与接地保护” → 检查单位和意义。

**答案**：总电流过大导致导线过热和火灾风险。

## 一句话收束

今天记住：**家庭电路并联，保护装置切断危险通路；火线—用电器—零线与接地保护。**

## 10分钟练习

1. **[基础·概念辨析]** 完成下面这项任务后，有同学的解释出现“湿手操作”。任务：识别三孔插座、总开关和漏电保护器，不接触市电。请指出应补充或改正的关键条件。

   **答案**：先按“火线—用电器—零线与接地保护”圈定研究对象和条件，再改正该判断；不能只写错误名称。
2. **[基础·读数/计算]** 多个大功率电器同插座有何风险。

   **答案**：总电流过大导致导线过热和火灾风险。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 围绕“家庭电路安全图”，标出研究对象、关键方向或变量，并用图得出“火线—用电器—零线与接地保护”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·证据与实验]** 完成“识别三孔插座、总开关和漏电保护器，不接触市电”时，写出要比较的对象、只改变或重点比较的条件，以及应记录的现象。

   **答案**：围绕“火线—用电器—零线与接地保护”完成一次清楚比较：先定对象和条件，再记录能支持或否定“家庭电路并联，保护装置切断危险通路”的现象；一次操作不能外推成普遍定律。
5. **[提升·解释论证]** 把下面的核心问题改成可检验的问题，并写出需要取得的证据：保险装置为什么装在火线上？

   **答案**：先圈定对象和条件，再用“火线—用电器—零线与接地保护”连接证据与结论。如果出现“开关接零线”，订正这个判断步骤后，再用一道同类题确认。

## 为什么错

- **开关接零线**：重画最简图，逐一核对方向、箭头、虚实线和标注。
- **湿手操作**：按对象、条件、单位逐项检查一遍。
- **做题中途漏条件**：在题目旁画“对象—条件—单位”三格，完成一格勾一格。
