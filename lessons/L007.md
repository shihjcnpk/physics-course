# 第7课：音调、响度和音色别混淆

## 今天只学一件事

回答：**同一首歌为什么能听出是谁唱的？**

## 0～2分钟｜为什么要学它？

先不要找公式。想象这个生活场景：弹不同长度橡皮筋并改变拨动力度。本课只追一个变化，不追所有细节。

## 2～5分钟｜先猜一猜

把答案先写成一句话：结果会怎样？你依据的是“看起来”，还是一个可检查的条件？先保留答案，不马上判对错。

## 5～10分钟｜看现象 / 做实验

任务：弹不同长度橡皮筋并改变拨动力度。

1. 指出研究对象。
2. 圈出改变的量和保持不变的量。
3. 记录一个现象或一组数据。
4. 立刻说一句：“我看到的证据是……”。

只改变本课研究的一个因素，取得一个清楚现象或一组可比较数据。



安全提示：使用小型、稳定、无尖锐边缘的器材；发现器材异常立即停止。

## 你发现了什么？

现象支持的最短结论是：**声音有音调、响度、音色三种特性**。若证据不足，只写“目前支持”，不要把猜想当结论。

## 10～14分钟｜把现象画出来，建立模型

画：**三种波形对比图**。图上只保留对象、关键方向/变量和边界。

模型句：**频率管高低、振幅管强弱、音色辨声源**。

## 14～17分钟｜正式物理知识

- 概念：声音有音调、响度、音色三种特性。
- 关系：本课无须背公式，先稳定概念和图。
- 本课不用计算公式。模型边界：频率管高低、振幅管强弱、音色辨声源。
- 先用图和证据判断，不把一句口诀套到所有情境。



## 17～19分钟｜一个典型例题

**题目**：用力拨同一根弦主要改变什么？

**六步建模**：对象是谁 → 已知什么 → 求什么 → 画最简图 → 选“频率管高低、振幅管强弱、音色辨声源” → 检查单位和意义。

**答案**：响度；弦的振动频率近似不变。

## 19～20分钟｜一句话收束

今天记住：**声音有音调、响度、音色三种特性；频率管高低、振幅管强弱、音色辨声源。**

## 10分钟练习

1. **概念判断**：用自己的话解释“声音有音调、响度、音色三种特性”。  
   **答案**：必须同时说出物理对象和关系：频率管高低、振幅管强弱、音色辨声源。只重复标题不算完成。
2. **条件辨认**：不用公式，只用“频率管高低、振幅管强弱、音色辨声源”判断并说明条件。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C3波形读错”。
3. **图示应用**：请画一张“三种波形对比图”，用图解释“频率管高低、振幅管强弱、音色辨声源”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：用力拨同一根弦主要改变什么。  
   **答案**：响度；弦的振动频率近似不变。关键模型：频率管高低、振幅管强弱、音色辨声源。
5. **情境与错因侦探**：同学完成“弹不同长度橡皮筋并改变拨动力度”后出现“C1三特性混淆”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C1三特性混淆**。先检查与“频率管高低、振幅管强弱、音色辨声源”直接相关的对象和条件，再决定重画图、重读数或重算。

## 为什么错

- C1三特性混淆：回到本课模型卡，重新指出对象和关键条件。
- C3波形读错：只修这一步，再做第4题；不要整课重听。
- 若是C9注意丢失：在题目旁画“对象—条件—单位”三格，完成一格勾一格。
