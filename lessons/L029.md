# 第29课：弹力与弹簧测力计

## 今天只学一件事

回答：**拉得越长，弹簧的拉力一定越大吗？**

## 0～2分钟｜为什么要学它？

先不要找公式。想象这个生活场景：检查零点、量程、分度值，体验并测量1 N与书的重力。本课只追一个变化，不追所有细节。

## 2～5分钟｜先猜并设计

把答案先写成一句话：结果会怎样？你依据的是“看起来”，还是一个可检查的条件？先保留答案，不马上判对错。

## 5～12分钟｜操作与取证

任务：检查零点、量程、分度值，体验并测量1 N与书的重力。

1. 指出研究对象。
2. 圈出改变的量和保持不变的量。
3. 记录一个现象或一组数据。
4. 立刻说一句：“我看到的证据是……”。

先写自变量、因变量和至少两个控制量；按安全规范完成操作，至少取得三组有效数据。若课堂器材未就绪，使用教师提供的同结构数据做分析，本实验仍需另行完成实操。

### 核心实验设计卡

- 自变量/主动改变：测量类，无自变量。
- 因变量/观察测量：力的示数。
- 关键控制与规范：校零、量程、分度值和受力方向。
- 证据记录：原始示数、单位及是否超量程。
- 结论规则：先描述数据共同趋势，再回答问题；异常数据不许静默删除，要复测或说明。


安全提示：使用小型、稳定、无尖锐边缘的器材；发现器材异常立即停止。 `CORE`实验应在教师或成人指导下完成。

## 你发现了什么？

现象支持的最短结论是：**弹性形变产生弹力且有弹性限度**。若证据不足，只写“目前支持”，不要把猜想当结论。

## 12～15分钟｜整理证据，建立模型

画：**测力计读数图**。图上只保留对象、关键方向/变量和边界。

模型句：**在限度内形变量反映力大小**。

## 15～17分钟｜正式物理知识

- 概念：弹性形变产生弹力且有弹性限度。
- 关系：本课无须背公式，先稳定概念和图。
- 本课不用计算公式。模型边界：在限度内形变量反映力大小。
- 先用图和证据判断，不把一句口诀套到所有情境。



## 17～19分钟｜一个典型例题

**题目**：测力计每大格1 N分5小格，指3小格？

**六步建模**：对象是谁 → 已知什么 → 求什么 → 画最简图 → 选“在限度内形变量反映力大小” → 检查单位和意义。

**答案**：0.6 N。

## 19～20分钟｜一句话收束

今天记住：**弹性形变产生弹力且有弹性限度；在限度内形变量反映力大小。**

## 10分钟练习

1. **概念判断**：用自己的话解释“弹性形变产生弹力且有弹性限度”。  
   **答案**：必须同时说出物理对象和关系：在限度内形变量反映力大小。只重复标题不算完成。
2. **条件辨认**：不用公式，只用“在限度内形变量反映力大小”判断并说明条件。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C7超过量程仍使用”。
3. **图示应用**：请画一张“测力计读数图”，用图解释“在限度内形变量反映力大小”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：测力计每大格1 N分5小格，指3小格。  
   **答案**：0.6 N。关键模型：在限度内形变量反映力大小。
5. **情境与错因侦探**：同学完成“检查零点、量程、分度值，体验并测量1 N与书的重力”后出现“C9未校零”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C9未校零**。先检查与“在限度内形变量反映力大小”直接相关的对象和条件，再决定重画图、重读数或重算。

## 为什么错

- C9未校零：回到本课模型卡，重新指出对象和关键条件。
- C7超过量程仍使用：只修这一步，再做第4题；不要整课重听。
- 若是C9注意丢失：在题目旁画“对象—条件—单位”三格，完成一格勾一格。
