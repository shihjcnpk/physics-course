# 第70课：能源与现代技术：用证据选择方案

## 今天只学一件事

回答：**一种能源方案“能用”，是否就一定适合这个场景？**

## 开课前｜数学准备

数学前置：百分数、大小比较。本课数学只服务于物理问题“一种能源方案“能用”，是否就一定适合这个场景？”。百分数：表示有效部分占总体的比例；大小比较：用同一标准比较证据。

**数学小补丁**：若不稳定，先做5分钟补丁：用一个生活数例复习百分数、大小比较，只练本课会用到的一步。

## 为什么要学它？

想一想这个生活场景：读取太阳能、风能和市电的三项数据，只为“节能小屋”选择一个组合方案。

## 先猜一猜

把答案先写成一句话：结果会怎样？你依据的是“看起来”，还是一个可检查的条件？先保留答案，不马上判对错。

## 看现象 / 做实验

任务：读取太阳能、风能和市电的三项数据，只为“节能小屋”选择一个组合方案。

1. 指出研究对象。
2. 圈出改变的量和保持不变的量。
3. 记录一个现象或一组数据。
4. 立刻说一句：“我看到的证据是……”。

只改变本课研究的一个因素，取得一个清楚现象或一组可比较数据。



安全提示：使用小型、稳定、无尖锐边缘的器材；发现器材异常立即停止。

## 你发现了什么？

现象支持的最短结论是：**能源方案要按需求比较稳定性、安全、环境和成本**。若证据不足，只写“目前支持”，不要把猜想当结论。

## 把现象画出来，建立模型

画：**方案评价矩阵**。图上只保留对象、关键方向/变量和边界。

模型句：**需求—证据—约束—方案—评价**。

## 正式物理知识

- 概念：能源方案要按需求比较稳定性、安全、环境和成本。
- 关系：本课无须背公式，先稳定概念和图。
- 本课不用计算公式。模型边界：需求—证据—约束—方案—评价。
- 先用图和证据判断，不把一句口诀套到所有情境。

**信息阅读卡（2.4.6）**：广播、移动通信和卫星通信可利用电磁波传递信息；这里只建立用途联系，不增加波长公式计算。

**跨学科项目卡（5.1—5.3）**：为节能小屋完成‘需求—证据—约束—方案—评价’五格表。至少比较能耗、安全、稳定性、材料和环境影响，不以单一指标下结论。

## 一个典型例题

**题目**：白天日照稳定、夜间用电持续，能否只装太阳能板？

**六步建模**：对象是谁 → 已知什么 → 求什么 → 画最简图 → 选“需求—证据—约束—方案—评价” → 检查单位和意义。

**答案**：不能只凭白天数据决定；还要考虑夜间供能、储能或备用电源。

## 一句话收束

今天记住：**能源方案要按需求比较稳定性、安全、环境和成本；需求—证据—约束—方案—评价。**

## 10分钟练习

1. **[基础·概念辨析]** 完成下面这项任务后，有同学的解释出现“把可再生能源等同于没有环境影响”。任务：读取太阳能、风能和市电的三项数据，只为“节能小屋”选择一个组合方案。请指出应补充或改正的关键条件。

   **答案**：先按“需求—证据—约束—方案—评价”圈定研究对象和条件，再改正该判断；不能只写错误名称。
2. **[基础·读数/计算]** 白天日照稳定、夜间用电持续，能否只装太阳能板。

   **答案**：不能只凭白天数据决定；还要考虑夜间供能、储能或备用电源。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 围绕“方案评价矩阵”，标出研究对象、关键方向或变量，并用图得出“需求—证据—约束—方案—评价”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·证据与实验]** 完成“读取太阳能、风能和市电的三项数据，只为“节能小屋”选择一个组合方案”时，写出要比较的对象、只改变或重点比较的条件，以及应记录的现象。

   **答案**：围绕“需求—证据—约束—方案—评价”完成一次清楚比较：先定对象和条件，再记录能支持或否定“能源方案要按需求比较稳定性、安全、环境和成本”的现象；一次操作不能外推成普遍定律。
5. **[提升·解释论证]** 把下面的核心问题改成可检验的问题，并写出需要取得的证据：一种能源方案“能用”，是否就一定适合这个场景？

   **答案**：先圈定对象和条件，再用“需求—证据—约束—方案—评价”连接证据与结论。如果出现“只看单一指标”，订正这个判断步骤后，再用一道同类题确认。

## 为什么错

- **只看单一指标**：重读题目，只圈出决定答案的条件，再作答。
- **把可再生能源等同于没有环境影响**：回到现象和核心句，用自己的话重新解释一次。
- **做题中途漏条件**：在题目旁画“对象—条件—单位”三格，完成一格勾一格。
