# 第57课：核心实验：串并联电压特点

## 今天只学一件事

回答：**两只串联灯怎样“分”电压？**

## 开课前｜数学准备

数学前置：加法、表格。本课数学只服务于物理问题“两只串联灯怎样“分”电压？”。加法：合并同一过程中的各段量；表格：配对记录同一条件下的数据。

**数学小补丁**：若不稳定，先做5分钟补丁：用一个生活数例复习加法、表格，只练本课会用到的一步。

## 为什么要学它？

想一想这个生活场景：分别测电源、各灯两端电压并换灯复测。

## 先猜并设计

把答案先写成一句话：结果会怎样？你依据的是“看起来”，还是一个可检查的条件？先保留答案，不马上判对错。

## 操作与取证

任务：分别测电源、各灯两端电压并换灯复测。

1. 指出研究对象。
2. 圈出改变的量和保持不变的量。
3. 记录一个现象或一组数据。
4. 立刻说一句：“我看到的证据是……”。

先写自变量、因变量和至少两个控制量；按安全规范完成操作，至少取得三组有效数据。若课堂器材未就绪，使用教师提供的同结构数据做分析，本实验仍需另行完成实操。

### 核心实验设计卡

- 自变量/主动改变：测量元件或支路。
- 因变量/观察测量：各部分两端电压。
- 关键控制与规范：电源、元件组合、量程和连接方式。
- 证据记录：串联总分电压与并联支路电压多组数据。
- 结论规则：先描述数据共同趋势，再回答问题；异常数据不许静默删除，要复测或说明。


安全提示：只用实验室低压直流电源；改接电路前先断电，禁止接触家庭市电。 `CORE`实验应在教师或成人指导下完成。

## 你发现了什么？

现象支持的最短结论是：**串联总电压等于各部分之和，并联各支路电压相等**。若证据不足，只写“目前支持”，不要把猜想当结论。

## 整理证据，建立模型

画：**串并联电压图**。图上只保留对象、关键方向/变量和边界。

模型句：**回路电压分配模型**。

## 正式物理知识

- 概念：串联总电压等于各部分之和，并联各支路电压相等。
- 关系：U总=U1+U2；U=U1=U2
- 为什么需要：用一个数量关系回答“两只串联灯怎样“分”电压？”。
- 量与单位：各电压均用V，电压表跨接在对应两端。
- 怎样变化：串联各部分电压之和等于电源两端总电压。
- 适用边界：先确认测量端点；不能把电流关系直接套给电压。



## 一个典型例题

**题目**：串联两灯1.2 V、1.8 V，电源电压？

**六步建模**：对象是谁 → 已知什么 → 求什么 → 画最简图 → 选“回路电压分配模型” → 检查单位和意义。

**答案**：3.0 V。

## 一句话收束

今天记住：**串联总电压等于各部分之和，并联各支路电压相等；回路电压分配模型。**

   **答案**：先按“回路电压分配模型”圈定研究对象和条件，再改正该判断；不能只写错误名称。
2. **[基础·读数/计算]** 串联两灯1.2 V、1.8 V，电源电压。

   **答案**：3.0 V。关键条件：对象、过程和单位必须配对。
3. **[典型·读图作图]** 围绕“串并联电压图”，标出研究对象、关键方向或变量，并用图得出“回路电压分配模型”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·证据与实验]** 本课核心实验怎样保证结论可信？写出主动改变的量、观察测量的量和关键控制条件。

   **答案**：主动改变：测量元件或支路；观察测量：各部分两端电压；关键控制：电源、元件组合、量程和连接方式；证据记录：串联总分电压与并联支路电压多组数据。
5. **[提升·解释论证]** 把下面的核心问题改成可检验的问题，并写出需要取得的证据：两只串联灯怎样“分”电压？

## 为什么错

- **测量端点错**：重画最简图，逐一核对方向、箭头、虚实线和标注。
- **把电流规律套给电压**：重读题目，只圈出决定答案的条件，再作答。
- **做题中途漏条件**：在题目旁画“对象—条件—单位”三格，完成一格勾一格。
