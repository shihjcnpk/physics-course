# 第16课：核心实验：光的反射定律

## 今天只学一件事

回答：**镜子能把光“弹”到哪里？**

## 0～2分钟｜为什么要学它？

先不要找公式。想象这个生活场景：用平面镜、纸屏和量角器改变入射角测三组数据。本课只追一个变化，不追所有细节。

## 2～5分钟｜先猜并设计

把答案先写成一句话：结果会怎样？你依据的是“看起来”，还是一个可检查的条件？先保留答案，不马上判对错。

## 5～12分钟｜操作与取证

任务：用平面镜、纸屏和量角器改变入射角测三组数据。

1. 指出研究对象。
2. 圈出改变的量和保持不变的量。
3. 记录一个现象或一组数据。
4. 立刻说一句：“我看到的证据是……”。

先写自变量、因变量和至少两个控制量；按安全规范完成操作，至少取得三组有效数据。若课堂器材未就绪，使用教师提供的同结构数据做分析，本实验仍需另行完成实操。

### 核心实验设计卡

- 自变量/主动改变：入射角。
- 因变量/观察测量：反射角和光路位置。
- 关键控制与规范：同一镜面、入射点和量角方法。
- 证据记录：不少于三组i与r及翻折光屏现象。
- 结论规则：先描述数据共同趋势，再回答问题；异常数据不许静默删除，要复测或说明。


安全提示：激光只能沿桌面低位传播并设置挡光板，严禁照眼、照人或照反光物。 `CORE`实验应在教师或成人指导下完成。

## 你发现了什么？

现象支持的最短结论是：**反射光线、入射光线和法线在同一平面内**。若证据不足，只写“目前支持”，不要把猜想当结论。

## 12～15分钟｜整理证据，建立模型

画：**反射光路图**。图上只保留对象、关键方向/变量和边界。

模型句：**反射角等于入射角，两线分居法线两侧**。

## 15～17分钟｜正式物理知识

- 概念：反射光线、入射光线和法线在同一平面内。
- 关系：∠r=∠i
- 为什么需要：用一个数量关系回答“镜子能把光“弹”到哪里？”。
- 量与单位：i、r都从法线量起，单位是度。
- 怎样变化：入射角增大时反射角等量增大。
- 适用边界：还要满足三线共面、两线分居法线两侧。



## 17～19分钟｜一个典型例题

**题目**：入射光与镜面夹30°，反射角是多少？

**六步建模**：对象是谁 → 已知什么 → 求什么 → 画最简图 → 选“反射角等于入射角，两线分居法线两侧” → 检查单位和意义。

**答案**：60°；入射角和反射角都相对法线测量。

## 19～20分钟｜一句话收束

今天记住：**反射光线、入射光线和法线在同一平面内；反射角等于入射角，两线分居法线两侧。**

## 10分钟练习

1. **概念判断**：用自己的话解释“反射光线、入射光线和法线在同一平面内”。  
   **答案**：必须同时说出物理对象和关系：反射角等于入射角，两线分居法线两侧。只重复标题不算完成。
2. **条件辨认**：写出∠r=∠i中各量对应的对象，并说一个不能直接使用它的情形。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C8由一组数据定律”。
3. **图示应用**：请画一张“反射光路图”，用图解释“反射角等于入射角，两线分居法线两侧”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：入射光与镜面夹30°，反射角是多少。  
   **答案**：60°；入射角和反射角都相对法线测量。关键模型：反射角等于入射角，两线分居法线两侧。
5. **情境与错因侦探**：同学完成“用平面镜、纸屏和量角器改变入射角测三组数据”后出现“C3角相对镜面量”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C3角相对镜面量**。先检查与“反射角等于入射角，两线分居法线两侧”直接相关的对象和条件，再决定重画图、重读数或重算。

## 为什么错

- C3角相对镜面量：回到本课模型卡，重新指出对象和关键条件。
- C8由一组数据定律：只修这一步，再做第4题；不要整课重听。
- 若是C9注意丢失：在题目旁画“对象—条件—单位”三格，完成一格勾一格。
