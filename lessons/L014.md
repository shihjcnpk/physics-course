# 第14课：升华、凝华与水循环

## 今天只学一件事

回答：**霜为什么不是从天空落下来的？**


## 开课前｜数学准备

数学前置：无。本课不要求新的数学工具，重点用观察、分类或画图表达证据。

**数学小补丁**：无需数学补丁；直接进入观察、比较或画图任务。
## 为什么要学它？

先不要找公式。想象这个生活场景：观察冷冻室霜或碘升华视频，只追踪物质去向。本课只追一个变化，不追所有细节。

## 先猜一猜

把答案先写成一句话：结果会怎样？你依据的是“看起来”，还是一个可检查的条件？先保留答案，不马上判对错。

## 看现象 / 做实验

任务：观察冷冻室霜或碘升华视频，只追踪物质去向。

1. 指出研究对象。
2. 圈出改变的量和保持不变的量。
3. 记录一个现象或一组数据。
4. 立刻说一句：“我看到的证据是……”。

只改变本课研究的一个因素，取得一个清楚现象或一组可比较数据。



安全提示：涉及热水或热源时由成人管理；温度计不碰容器底壁，禁止直接加热密闭容器。

## 你发现了什么？

现象支持的最短结论是：**物质可直接在固态和气态间变化**。若证据不足，只写“目前支持”，不要把猜想当结论。

## 把现象画出来，建立模型

画：**水循环箭头图**。图上只保留对象、关键方向/变量和边界。

模型句：**固↔气与水循环状态链**。

## 正式物理知识

- 概念：物质可直接在固态和气态间变化。
- 关系：本课无须背公式，先稳定概念和图。
- 本课不用计算公式。模型边界：固↔气与水循环状态链。
- 先用图和证据判断，不把一句口诀套到所有情境。

**课后教材融合卡（不占本课20分钟）**：在厨房照片中寻找熔化、汽化、液化、升华或凝华现象，逐一写清物质、初态和末态。

## 一个典型例题

**题目**：窗上冰花通常形成在哪一侧？

**六步建模**：对象是谁 → 已知什么 → 求什么 → 画最简图 → 选“固↔气与水循环状态链” → 检查单位和意义。

**答案**：室内侧；水蒸气遇冷凝华。

## 一句话收束

今天记住：**物质可直接在固态和气态间变化；固↔气与水循环状态链。**

## 10分钟练习

1. **[基础·北京题型：概念辨析]** 冷冻室内壁的霜不是液态水冻成的。写出形成霜的初态、末态和名称。

   **答案**：水蒸气由气态直接变为固态冰晶，属于凝华。
2. **[基础·北京题型：读数/计算]** 窗上冰花通常形成在哪一侧。

   **答案**：室内侧；水蒸气遇冷凝华。关键条件：对象、过程和单位必须配对。
3. **[典型·北京题型：读图作图]** 围绕“水循环箭头图”，标出研究对象、关键方向或变量，并用图得出“固↔气与水循环状态链”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·北京题型：实验探究]** 要完成“观察冷冻室霜或碘升华视频，只追踪物质去向”，写出本次只改变或重点比较的量，以及判断结论所需的证据。

   **答案**：围绕“固↔气与水循环状态链”只改变一个关键因素，其他条件保持一致；至少取得可比较的数据或清楚现象，不能由一次偶然结果下结论。
5. **[提升·北京题型：解释/论证]** 解释人工降雪与窗上冰花时，为什么必须先追踪物质的初态和末态？

   **答案**：物态变化名称由初态到末态的路径决定；只看最终是固态，无法区分凝固和凝华。

## 为什么错

- C4忽略冷热位置：只修这一步，再做第4题；不要整课重听。
- 若是C9注意丢失：在题目旁画“对象—条件—单位”三格，完成一格勾一格。
