# 第27课：力的三要素与示意图

## 今天只学一件事

回答：**同样大小的力，为什么推门位置不同效果不同？**

## 0～2分钟｜为什么要学它？

先不要找公式。想象这个生活场景：在门上不同位置推，画出作用点和方向。本课只追一个变化，不追所有细节。

## 2～5分钟｜先猜一猜

把答案先写成一句话：结果会怎样？你依据的是“看起来”，还是一个可检查的条件？先保留答案，不马上判对错。

## 5～10分钟｜看现象 / 做实验

任务：在门上不同位置推，画出作用点和方向。

1. 指出研究对象。
2. 圈出改变的量和保持不变的量。
3. 记录一个现象或一组数据。
4. 立刻说一句：“我看到的证据是……”。

只改变本课研究的一个因素，取得一个清楚现象或一组可比较数据。



安全提示：使用小型、稳定、无尖锐边缘的器材；发现器材异常立即停止。

## 你发现了什么？

现象支持的最短结论是：**力有大小、方向、作用点**。若证据不足，只写“目前支持”，不要把猜想当结论。

## 10～14分钟｜把现象画出来，建立模型

画：**规范力箭头图**。图上只保留对象、关键方向/变量和边界。

模型句：**用带比例或标值箭头表示力**。

## 14～17分钟｜正式物理知识

- 概念：力有大小、方向、作用点。
- 关系：本课无须背公式，先稳定概念和图。
- 本课不用计算公式。模型边界：用带比例或标值箭头表示力。
- 先用图和证据判断，不把一句口诀套到所有情境。



## 17～19分钟｜一个典型例题

**题目**：画水平向右5 N的推力？

**六步建模**：对象是谁 → 已知什么 → 求什么 → 画最简图 → 选“用带比例或标值箭头表示力” → 检查单位和意义。

**答案**：箭头起于作用点、向右并标F=5 N。

## 19～20分钟｜一句话收束

今天记住：**力有大小、方向、作用点；用带比例或标值箭头表示力。**

## 10分钟练习

1. **概念判断**：用自己的话解释“力有大小、方向、作用点”。  
   **答案**：必须同时说出物理对象和关系：用带比例或标值箭头表示力。只重复标题不算完成。
2. **条件辨认**：不用公式，只用“用带比例或标值箭头表示力”判断并说明条件。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C6漏力值单位”。
3. **图示应用**：请画一张“规范力箭头图”，用图解释“用带比例或标值箭头表示力”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：画水平向右5 N的推力。  
   **答案**：箭头起于作用点、向右并标F=5 N。关键模型：用带比例或标值箭头表示力。
5. **情境与错因侦探**：同学完成“在门上不同位置推，画出作用点和方向”后出现“C3箭头起点错”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C3箭头起点错**。先检查与“用带比例或标值箭头表示力”直接相关的对象和条件，再决定重画图、重读数或重算。

## 为什么错

- C3箭头起点错：回到本课模型卡，重新指出对象和关键条件。
- C6漏力值单位：只修这一步，再做第4题；不要整课重听。
- 若是C9注意丢失：在题目旁画“对象—条件—单位”三格，完成一格勾一格。
