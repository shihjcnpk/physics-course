# 第27课：力的三要素与示意图

## 今天只学一件事

回答：**同样大小的力，为什么推门位置不同效果不同？**


## 开课前｜数学准备

数学前置：比例、方向。把比例、方向用于真实测量、图示或数量关系。

**数学小补丁**：若不稳定，先做5分钟补丁：用一个生活数例复习比例、方向，只练本课会用到的一步。

## 为什么要学它？

想一想这个生活场景：在门上不同位置推，画出作用点和方向。

## 先猜一猜

把答案先写成一句话：结果会怎样？你依据的是“看起来”，还是一个可检查的条件？先保留答案，不马上判对错。

## 看现象 / 做实验

任务：在门上不同位置推，画出作用点和方向。

1. 指出研究对象。
2. 圈出改变的量和保持不变的量。
3. 记录一个现象或一组数据。
4. 立刻说一句：“我看到的证据是……”。

只改变本课研究的一个因素，取得一个清楚现象或一组可比较数据。



安全提示：使用小型、稳定、无尖锐边缘的器材；发现器材异常立即停止。

## 你发现了什么？

现象支持的最短结论是：**力有大小、方向、作用点**。若证据不足，只写“目前支持”，不要把猜想当结论。

## 把现象画出来，建立模型

画：**规范力箭头图**。图上只保留对象、关键方向/变量和边界。

模型句：**用带比例或标值箭头表示力**。

## 正式物理知识

- 概念：力有大小、方向、作用点。
- 关系：本课无须背公式，先稳定概念和图。
- 本课不用计算公式。模型边界：用带比例或标值箭头表示力。
- 先用图和证据判断，不把一句口诀套到所有情境。



## 一个典型例题

**题目**：画水平向右5 N的推力？

**六步建模**：对象是谁 → 已知什么 → 求什么 → 画最简图 → 选“用带比例或标值箭头表示力” → 检查单位和意义。

**答案**：箭头起于作用点、向右并标F=5 N。

## 一句话收束

今天记住：**力有大小、方向、作用点；用带比例或标值箭头表示力。**

## 10分钟练习

1. **[基础·北京题型：概念辨析]** 在“在门上不同位置推，画出作用点和方向”中，有同学出现了“漏力值单位”。这个结论可靠吗？

   **答案**：不可靠。应先按“用带比例或标值箭头表示力”核对研究对象和条件。
2. **[基础·北京题型：读数/计算]** 画水平向右5 N的推力。

   **答案**：箭头起于作用点、向右并标F=5 N。关键条件：对象、过程和单位必须配对。
3. **[典型·北京题型：读图作图]** 围绕“规范力箭头图”，标出研究对象、关键方向或变量，并用图得出“用带比例或标值箭头表示力”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·北京题型：实验探究]** 要完成“在门上不同位置推，画出作用点和方向”，写出本次只改变或重点比较的量，以及判断结论所需的证据。

   **答案**：围绕“用带比例或标值箭头表示力”只改变一个关键因素，其他条件保持一致；至少取得可比较的数据或清楚现象，不能由一次偶然结果下结论。
5. **[提升·北京题型：解释/论证]** 把“同样大小的力，为什么推门位置不同效果不同？”改成可检验的问题，并写出需要取得的证据。

   **答案**：先圈定对象和条件，再用“用带比例或标值箭头表示力”连接证据与结论。如果出现“箭头起点错”，订正这个判断步骤后，再用一道同类题确认。

## 为什么错

- **箭头起点错**：重画最简图，逐一核对方向、箭头、虚实线和标注。
- **漏力值单位**：先统一单位，再把数值代入关系式。
- **做题中途漏条件**：在题目旁画“对象—条件—单位”三格，完成一格勾一格。
