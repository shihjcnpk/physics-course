# 第49课：比热容：相同热量为何升温不同

## 今天只学一件事

回答：**海边昼夜温差为什么比沙漠小？**

## 0～2分钟｜为什么要学它？

先不要找公式。想象这个生活场景：等质量水和沙接受相同加热，比较升温。本课只追一个变化，不追所有细节。

## 2～5分钟｜先猜一猜

把答案先写成一句话：结果会怎样？你依据的是“看起来”，还是一个可检查的条件？先保留答案，不马上判对错。

## 5～10分钟｜看现象 / 做实验

任务：等质量水和沙接受相同加热，比较升温。

1. 指出研究对象。
2. 圈出改变的量和保持不变的量。
3. 记录一个现象或一组数据。
4. 立刻说一句：“我看到的证据是……”。

只改变本课研究的一个因素，取得一个清楚现象或一组可比较数据。



安全提示：涉及热水或热源时由成人管理；温度计不碰容器底壁，禁止直接加热密闭容器。

## 你发现了什么？

现象支持的最短结论是：**比热容表示单位质量升高1℃所需热量**。若证据不足，只写“目前支持”，不要把猜想当结论。

## 10～14分钟｜把现象画出来，建立模型

画：**水沙升温曲线图**。图上只保留对象、关键方向/变量和边界。

模型句：**质量、温差、物质共同决定吸热**。

## 14～17分钟｜正式物理知识

- 概念：比热容表示单位质量升高1℃所需热量。
- 关系：Q=cmΔT
- 为什么需要：用一个数量关系回答“海边昼夜温差为什么比沙漠小？”。
- 量与单位：c用J/(kg·℃)，m用kg，ΔT是温度变化量，Q用J。
- 怎样变化：同质量同温差时c越大吸放热越多。
- 适用边界：适用于无物态变化的吸放热计算；ΔT不是末温。



## 17～19分钟｜一个典型例题

**题目**：2 kg水升高5℃，c=4.2×10³，吸热？

**六步建模**：对象是谁 → 已知什么 → 求什么 → 画最简图 → 选“质量、温差、物质共同决定吸热” → 检查单位和意义。

**答案**：4.2×10^4 J。

## 19～20分钟｜一句话收束

今天记住：**比热容表示单位质量升高1℃所需热量；质量、温差、物质共同决定吸热。**

## 10分钟练习

1. **概念判断**：用自己的话解释“比热容表示单位质量升高1℃所需热量”。  
   **答案**：必须同时说出物理对象和关系：质量、温差、物质共同决定吸热。只重复标题不算完成。
2. **条件辨认**：写出Q=cmΔT中各量对应的对象，并说一个不能直接使用它的情形。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C6科学记数法错”。
3. **图示应用**：请画一张“水沙升温曲线图”，用图解释“质量、温差、物质共同决定吸热”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：2 kg水升高5℃，c=4.2×10³，吸热。  
   **答案**：4.2×10^4 J。关键模型：质量、温差、物质共同决定吸热。
5. **情境与错因侦探**：同学完成“等质量水和沙接受相同加热，比较升温”后出现“C5温差用末温”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C5温差用末温**。先检查与“质量、温差、物质共同决定吸热”直接相关的对象和条件，再决定重画图、重读数或重算。

## 为什么错

- C5温差用末温：回到本课模型卡，重新指出对象和关键条件。
- C6科学记数法错：只修这一步，再做第4题；不要整课重听。
- 若是C9注意丢失：在题目旁画“对象—条件—单位”三格，完成一格勾一格。
