# 第20课：核心实验：凸透镜成像规律

## 今天只学一件事

回答：**物体靠近透镜，像会怎样变？**

## 0～2分钟｜为什么要学它？

先不要找公式。想象这个生活场景：固定焦距，改变物距并在光屏上找清晰像。本课只追一个变化，不追所有细节。

## 2～5分钟｜先猜并设计

把答案先写成一句话：结果会怎样？你依据的是“看起来”，还是一个可检查的条件？先保留答案，不马上判对错。

## 5～12分钟｜操作与取证

任务：固定焦距，改变物距并在光屏上找清晰像。

1. 指出研究对象。
2. 圈出改变的量和保持不变的量。
3. 记录一个现象或一组数据。
4. 立刻说一句：“我看到的证据是……”。

先写自变量、因变量和至少两个控制量；按安全规范完成操作，至少取得三组有效数据。若课堂器材未就绪，使用教师提供的同结构数据做分析，本实验仍需另行完成实操。

### 核心实验设计卡

- 自变量/主动改变：物距u。
- 因变量/观察测量：像距、大小、正倒和虚实。
- 关键控制与规范：同一凸透镜、同一物体、同一光具座。
- 证据记录：u相对f和2f的多区间记录。
- 结论规则：先描述数据共同趋势，再回答问题；异常数据不许静默删除，要复测或说明。


安全提示：不用太阳作光源，不通过透镜直视太阳；优先使用低温LED光源。 `CORE`实验应在教师或成人指导下完成。

## 你发现了什么？

现象支持的最短结论是：**像的性质随物距区间改变**。若证据不足，只写“目前支持”，不要把猜想当结论。

## 12～15分钟｜整理证据，建立模型

画：**光具座区间图**。图上只保留对象、关键方向/变量和边界。

模型句：**物距—焦距区间决定像的位置与性质**。

## 15～17分钟｜正式物理知识

- 概念：像的性质随物距区间改变。
- 关系：本课无须背公式，先稳定概念和图。
- 本课不用计算公式。模型边界：结论针对薄凸透镜近轴成像的初中实验模型，先比较物距与f、2f。
- 先用图和证据判断，不把一句口诀套到所有情境。



## 17～19分钟｜一个典型例题

**题目**：物距大于2f时像有何特点？

**六步建模**：对象是谁 → 已知什么 → 求什么 → 画最简图 → 选“物距—焦距区间决定像的位置与性质” → 检查单位和意义。

**答案**：倒立、缩小、实像，像在f与2f之间。

## 19～20分钟｜一句话收束

今天记住：**像的性质随物距区间改变；物距—焦距区间决定像的位置与性质。**

## 10分钟练习

1. **概念判断**：用自己的话解释“像的性质随物距区间改变”。  
   **答案**：必须同时说出物理对象和关系：物距—焦距区间决定像的位置与性质。只重复标题不算完成。
2. **条件辨认**：不用公式，只用“物距—焦距区间决定像的位置与性质”判断并说明条件。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C8找不到像就下结论”。
3. **图示应用**：请画一张“光具座区间图”，用图解释“物距—焦距区间决定像的位置与性质”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：物距大于2f时像有何特点。  
   **答案**：倒立、缩小、实像，像在f与2f之间。关键模型：物距—焦距区间决定像的位置与性质。
5. **情境与错因侦探**：同学完成“固定焦距，改变物距并在光屏上找清晰像”后出现“C4未先比较u与f”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C4未先比较u与f**。先检查与“物距—焦距区间决定像的位置与性质”直接相关的对象和条件，再决定重画图、重读数或重算。

## 为什么错

- C4未先比较u与f：回到本课模型卡，重新指出对象和关键条件。
- C8找不到像就下结论：只修这一步，再做第4题；不要整课重听。
- 若是C9注意丢失：在题目旁画“对象—条件—单位”三格，完成一格勾一格。
