# 第32课：惯性：物体想保持原状态

## 今天只学一件事

回答：**公交车急刹车，人为什么向前倾？**

## 0～2分钟｜为什么要学它？

先不要找公式。想象这个生活场景：抽走纸片观察硬币落杯，再口述前后状态。本课只追一个变化，不追所有细节。

## 2～5分钟｜先猜一猜

把答案先写成一句话：结果会怎样？你依据的是“看起来”，还是一个可检查的条件？先保留答案，不马上判对错。

## 5～10分钟｜看现象 / 做实验

任务：抽走纸片观察硬币落杯，再口述前后状态。

1. 指出研究对象。
2. 圈出改变的量和保持不变的量。
3. 记录一个现象或一组数据。
4. 立刻说一句：“我看到的证据是……”。

只改变本课研究的一个因素，取得一个清楚现象或一组可比较数据。



安全提示：使用小型、稳定、无尖锐边缘的器材；发现器材异常立即停止。

## 你发现了什么？

现象支持的最短结论是：**一切物体都有保持原运动状态的性质**。若证据不足，只写“目前支持”，不要把猜想当结论。

## 10～14分钟｜把现象画出来，建立模型

画：**刹车状态时间轴**。图上只保留对象、关键方向/变量和边界。

模型句：**刹车前后分别比较人和车状态**。

## 14～17分钟｜正式物理知识

- 概念：一切物体都有保持原运动状态的性质。
- 关系：本课无须背公式，先稳定概念和图。
- 本课不用计算公式。模型边界：刹车前后分别比较人和车状态。
- 先用图和证据判断，不把一句口诀套到所有情境。



## 17～19分钟｜一个典型例题

**题目**：跳远助跑为什么有用？

**六步建模**：对象是谁 → 已知什么 → 求什么 → 画最简图 → 选“刹车前后分别比较人和车状态” → 检查单位和意义。

**答案**：起跳后身体因惯性保持较大向前速度。

## 19～20分钟｜一句话收束

今天记住：**一切物体都有保持原运动状态的性质；刹车前后分别比较人和车状态。**

## 10分钟练习

1. **概念判断**：用自己的话解释“一切物体都有保持原运动状态的性质”。  
   **答案**：必须同时说出物理对象和关系：刹车前后分别比较人和车状态。只重复标题不算完成。
2. **条件辨认**：不用公式，只用“刹车前后分别比较人和车状态”判断并说明条件。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C4漏原状态”。
3. **图示应用**：请画一张“刹车状态时间轴”，用图解释“刹车前后分别比较人和车状态”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：跳远助跑为什么有用。  
   **答案**：起跳后身体因惯性保持较大向前速度。关键模型：刹车前后分别比较人和车状态。
5. **情境与错因侦探**：同学完成“抽走纸片观察硬币落杯，再口述前后状态”后出现“C1说“受到惯性力””。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C1说“受到惯性力”**。先检查与“刹车前后分别比较人和车状态”直接相关的对象和条件，再决定重画图、重读数或重算。

## 为什么错

- C1说“受到惯性力”：回到本课模型卡，重新指出对象和关键条件。
- C4漏原状态：只修这一步，再做第4题；不要整课重听。
- 若是C9注意丢失：在题目旁画“对象—条件—单位”三格，完成一格勾一格。
