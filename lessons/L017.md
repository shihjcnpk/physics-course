# 第17课：核心实验：平面镜成像

## 今天只学一件事

回答：**镜中的像能落在纸屏上吗？**

## 0～2分钟｜为什么要学它？

先不要找公式。想象这个生活场景：玻璃板前后用两支相同蜡烛定位像，再放光屏。本课只追一个变化，不追所有细节。

## 2～5分钟｜先猜并设计

把答案先写成一句话：结果会怎样？你依据的是“看起来”，还是一个可检查的条件？先保留答案，不马上判对错。

## 5～12分钟｜操作与取证

任务：玻璃板前后用两支相同蜡烛定位像，再放光屏。

1. 指出研究对象。
2. 圈出改变的量和保持不变的量。
3. 记录一个现象或一组数据。
4. 立刻说一句：“我看到的证据是……”。

先写自变量、因变量和至少两个控制量；按安全规范完成操作，至少取得三组有效数据。若课堂器材未就绪，使用教师提供的同结构数据做分析，本实验仍需另行完成实操。

### 核心实验设计卡

- 自变量/主动改变：物距。
- 因变量/观察测量：像距、像大小和能否承接。
- 关键控制与规范：同一玻璃板、相同物体、测量基准。
- 证据记录：多组物距像距及光屏检验。
- 结论规则：先描述数据共同趋势，再回答问题；异常数据不许静默删除，要复测或说明。


安全提示：玻璃板边缘须包边并固定；优先使用LED物体，若用蜡烛须由成人管理火源。 `CORE`实验应在教师或成人指导下完成。

## 你发现了什么？

现象支持的最短结论是：**平面镜成等大正立虚像**。若证据不足，只写“目前支持”，不要把猜想当结论。

## 12～15分钟｜整理证据，建立模型

画：**玻璃板成像图**。图上只保留对象、关键方向/变量和边界。

模型句：**像物关于镜面对称**。

## 15～17分钟｜正式物理知识

- 概念：平面镜成等大正立虚像。
- 关系：像距=物距
- 为什么需要：用一个数量关系回答“镜中的像能落在纸屏上吗？”。
- 量与单位：像距和物距都沿镜面法线测量，单位相同。
- 怎样变化：物体远离镜面，像以相同距离远离。
- 适用边界：只描述平面镜成像，不表示像能落在光屏上。



## 17～19分钟｜一个典型例题

**题目**：人离镜1 m，像离人多远？

**六步建模**：对象是谁 → 已知什么 → 求什么 → 画最简图 → 选“像物关于镜面对称” → 检查单位和意义。

**答案**：2 m；像在镜后1 m。

## 19～20分钟｜一句话收束

今天记住：**平面镜成等大正立虚像；像物关于镜面对称。**

## 10分钟练习

1. **概念判断**：用自己的话解释“平面镜成等大正立虚像”。  
   **答案**：必须同时说出物理对象和关系：像物关于镜面对称。只重复标题不算完成。
2. **条件辨认**：写出像距=物距中各量对应的对象，并说一个不能直接使用它的情形。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C5漏总距离”。
3. **图示应用**：请画一张“玻璃板成像图”，用图解释“像物关于镜面对称”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：人离镜1 m，像离人多远。  
   **答案**：2 m；像在镜后1 m。关键模型：像物关于镜面对称。
5. **情境与错因侦探**：同学完成“玻璃板前后用两支相同蜡烛定位像，再放光屏”后出现“C3把像画成实线光线会聚”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C3把像画成实线光线会聚**。先检查与“像物关于镜面对称”直接相关的对象和条件，再决定重画图、重读数或重算。

## 为什么错

- C3把像画成实线光线会聚：回到本课模型卡，重新指出对象和关键条件。
- C5漏总距离：只修这一步，再做第4题；不要整课重听。
- 若是C9注意丢失：在题目旁画“对象—条件—单位”三格，完成一格勾一格。
