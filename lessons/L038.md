# 第38课：浮力：浸在流体里的向上作用

## 今天只学一件事

回答：**铁块在水里为什么“变轻”？**

## 0～2分钟｜为什么要学它？

先不要找公式。想象这个生活场景：先在空气再浸水读取测力计，比较示数。本课只追一个变化，不追所有细节。

## 2～5分钟｜先猜一猜

把答案先写成一句话：结果会怎样？你依据的是“看起来”，还是一个可检查的条件？先保留答案，不马上判对错。

## 5～10分钟｜看现象 / 做实验

任务：先在空气再浸水读取测力计，比较示数。

1. 指出研究对象。
2. 圈出改变的量和保持不变的量。
3. 记录一个现象或一组数据。
4. 立刻说一句：“我看到的证据是……”。

只改变本课研究的一个因素，取得一个清楚现象或一组可比较数据。



安全提示：使用小型、稳定、无尖锐边缘的器材；发现器材异常立即停止。

## 你发现了什么？

现象支持的最短结论是：**浮力是流体对浸入物体向上的作用**。若证据不足，只写“目前支持”，不要把猜想当结论。

## 10～14分钟｜把现象画出来，建立模型

画：**称重法受力图**。图上只保留对象、关键方向/变量和边界。

模型句：**弹簧测力计示数差测浮力**。

## 14～17分钟｜正式物理知识

- 概念：浮力是流体对浸入物体向上的作用。
- 关系：F浮=G-F示
- 为什么需要：用一个数量关系回答“铁块在水里为什么“变轻”？”。
- 量与单位：G和F示均用N，差值为浮力。
- 怎样变化：测力计示数越小，称重法得到的浮力越大。
- 适用边界：物体不得触底或被其他物体支撑；空气浮力通常按初中近似忽略。



## 17～19分钟｜一个典型例题

**题目**：空气5 N、水中3 N，浮力？

**六步建模**：对象是谁 → 已知什么 → 求什么 → 画最简图 → 选“弹簧测力计示数差测浮力” → 检查单位和意义。

**答案**：2 N。

## 19～20分钟｜一句话收束

今天记住：**浮力是流体对浸入物体向上的作用；弹簧测力计示数差测浮力。**

## 10分钟练习

1. **概念判断**：用自己的话解释“浮力是流体对浸入物体向上的作用”。  
   **答案**：必须同时说出物理对象和关系：弹簧测力计示数差测浮力。只重复标题不算完成。
2. **条件辨认**：写出F浮=G-F示中各量对应的对象，并说一个不能直接使用它的情形。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C3漏竖直向上”。
3. **图示应用**：请画一张“称重法受力图”，用图解释“弹簧测力计示数差测浮力”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：空气5 N、水中3 N，浮力。  
   **答案**：2 N。关键模型：弹簧测力计示数差测浮力。
5. **情境与错因侦探**：同学完成“先在空气再浸水读取测力计，比较示数”后出现“C2把示数当浮力”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C2把示数当浮力**。先检查与“弹簧测力计示数差测浮力”直接相关的对象和条件，再决定重画图、重读数或重算。
