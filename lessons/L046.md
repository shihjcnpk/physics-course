# 第46课：机械效率：有用功占多少

## 今天只学一件事

回答：**使用机械省了力，是否也省了功？**

## 0～2分钟｜为什么要学它？

先不要找公式。想象这个生活场景：用定滑轮和动滑轮提同一物体，比较有用功、额外功和总功。本课只追一个变化，不追所有细节。

## 2～5分钟｜先猜一猜

把答案先写成一句话：结果会怎样？你依据的是“看起来”，还是一个可检查的条件？先保留答案，不马上判对错。

## 5～10分钟｜看现象 / 做实验

任务：用定滑轮和动滑轮提同一物体，比较有用功、额外功和总功。

1. 指出研究对象。
2. 圈出改变的量和保持不变的量。
3. 记录一个现象或一组数据。
4. 立刻说一句：“我看到的证据是……”。

只改变本课研究的一个因素，取得一个清楚现象或一组可比较数据。



安全提示：使用小型、稳定、无尖锐边缘的器材；发现器材异常立即停止。

## 你发现了什么？

现象支持的最短结论是：**机械效率表示有用功占总功的比例**。若证据不足，只写“目前支持”，不要把猜想当结论。

## 10～14分钟｜把现象画出来，建立模型

画：**有用额外总功流图**。图上只保留对象、关键方向/变量和边界。

模型句：**有用功、额外功与总功的能量账本**。

## 14～17分钟｜正式物理知识

- 概念：机械效率表示有用功占总功的比例。
- 关系：η=W有/W总
- 为什么需要：用一个数量关系回答“使用机械省了力，是否也省了功？”。
- 量与单位：两种功单位相同，效率常写百分数。
- 怎样变化：额外功减少时效率提高。
- 适用边界：实际机械0<η<100%；机械可以省力或省距离，但不能省功。

**机械发展阅读卡（3.2.4）**：杠杆、滑轮等机械能改变力或距离的安排，推动劳动工具发展；阅读卡不新增复杂机械计算。

## 17～19分钟｜一个典型例题

**题目**：有用功80 J、总功100 J，效率？

**六步建模**：对象是谁 → 已知什么 → 求什么 → 画最简图 → 选“有用功、额外功与总功的能量账本” → 检查单位和意义。

**答案**：80%；效率不可能超过100%。

## 19～20分钟｜一句话收束

今天记住：**机械效率表示有用功占总功的比例；有用功、额外功与总功的能量账本。**

## 10分钟练习

1. **概念判断**：用自己的话解释“机械效率表示有用功占总功的比例”。  
   **答案**：必须同时说出物理对象和关系：有用功、额外功与总功的能量账本。只重复标题不算完成。
2. **条件辨认**：写出η=W有/W总中各量对应的对象，并说一个不能直接使用它的情形。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C5百分数错误”。
3. **图示应用**：请画一张“有用额外总功流图”，用图解释“有用功、额外功与总功的能量账本”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：有用功80 J、总功100 J，效率。  
   **答案**：80%；效率不可能超过100%。关键模型：有用功、额外功与总功的能量账本。
5. **情境与错因侦探**：同学完成“用定滑轮和动滑轮提同一物体，比较有用功、额外功和总功”后出现“C7说机械省功”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C7说机械省功**。先检查与“有用功、额外功与总功的能量账本”直接相关的对象和条件，再决定重画图、重读数或重算。

## 为什么错

- C7说机械省功：回到本课模型卡，重新指出对象和关键条件。
- C5百分数错误：只修这一步，再做第4题；不要整课重听。
- 若是C9注意丢失：在题目旁画“对象—条件—单位”三格，完成一格勾一格。
