# 第46课：机械效率：有用功占多少

## 今天只学一件事

回答：**使用机械省了力，是否也省了功？**


## 开课前｜数学准备

数学前置：分数、百分数。把分数、百分数用于真实测量、图示或数量关系。

**数学小补丁**：若不稳定，先做5分钟补丁：用一个生活数例复习分数、百分数，只练本课会用到的一步。

## 为什么要学它？

先不要找公式。想象这个生活场景：用定滑轮和动滑轮提同一物体，比较有用功、额外功和总功。本课只追一个变化，不追所有细节。

## 先猜一猜

把答案先写成一句话：结果会怎样？你依据的是“看起来”，还是一个可检查的条件？先保留答案，不马上判对错。

## 看现象 / 做实验

任务：用定滑轮和动滑轮提同一物体，比较有用功、额外功和总功。

1. 指出研究对象。
2. 圈出改变的量和保持不变的量。
3. 记录一个现象或一组数据。
4. 立刻说一句：“我看到的证据是……”。

只改变本课研究的一个因素，取得一个清楚现象或一组可比较数据。



安全提示：使用小型、稳定、无尖锐边缘的器材；发现器材异常立即停止。

## 你发现了什么？

现象支持的最短结论是：**机械效率表示有用功占总功的比例**。若证据不足，只写“目前支持”，不要把猜想当结论。

## 把现象画出来，建立模型

画：**有用额外总功流图**。图上只保留对象、关键方向/变量和边界。

模型句：**有用功、额外功与总功的能量账本**。

## 正式物理知识

- 概念：机械效率表示有用功占总功的比例。
- 关系：η=W有/W总
- 为什么需要：用一个数量关系回答“使用机械省了力，是否也省了功？”。
- 量与单位：两种功单位相同，效率常写百分数。
- 怎样变化：额外功减少时效率提高。
- 适用边界：实际机械0<η<100%；机械可以省力或省距离，但不能省功。

**机械发展阅读卡（3.2.4）**：杠杆、滑轮等机械能改变力或距离的安排，推动劳动工具发展；阅读卡不新增复杂机械计算。

## 一个典型例题

**题目**：有用功80 J、总功100 J，效率？

**六步建模**：对象是谁 → 已知什么 → 求什么 → 画最简图 → 选“有用功、额外功与总功的能量账本” → 检查单位和意义。

**答案**：80%；效率不可能超过100%。

## 一句话收束

今天记住：**机械效率表示有用功占总功的比例；有用功、额外功与总功的能量账本。**

## 10分钟练习

1. **[基础·北京题型：概念辨析]** 在“用定滑轮和动滑轮提同一物体，比较有用功、额外功和总功”中，有同学忽略了“C5百分数错误”。这个结论可靠吗？

   **答案**：不可靠。应先按“有用功、额外功与总功的能量账本”核对研究对象和条件。
2. **[基础·北京题型：读数/计算]** 有用功80 J、总功100 J，效率。

   **答案**：80%；效率不可能超过100%。关键条件：对象、过程和单位必须配对。
3. **[典型·北京题型：读图作图]** 围绕“有用额外总功流图”，标出研究对象、关键方向或变量，并用图得出“有用功、额外功与总功的能量账本”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·北京题型：实验探究]** 要完成“用定滑轮和动滑轮提同一物体，比较有用功、额外功和总功”，写出本次只改变或重点比较的量，以及判断结论所需的证据。

   **答案**：围绕“有用功、额外功与总功的能量账本”只改变一个关键因素，其他条件保持一致；至少取得可比较的数据或清楚现象，不能由一次偶然结果下结论。
5. **[提升·北京题型：解释/论证]** 把“使用机械省了力，是否也省了功？”改成可检验的问题，并写出需要取得的证据。

   **答案**：先圈定对象和条件，再用“有用功、额外功与总功的能量账本”连接证据与结论。若出现“C7说机械省功”，归入 **C7说机械省功** 并只修对应步骤。
