# 第3课：速度：每1秒走多远

## 今天只学一件事

回答：**路程和时间都不同，怎样公平比快慢？**

## 0～2分钟｜为什么要学它？

先不要找公式。想象这个生活场景：比较两辆玩具车不同路程与时间，统一到每1秒。本课只追一个变化，不追所有细节。

## 2～5分钟｜先猜一猜

把答案先写成一句话：结果会怎样？你依据的是“看起来”，还是一个可检查的条件？先保留答案，不马上判对错。

## 5～10分钟｜看现象 / 做实验

任务：比较两辆玩具车不同路程与时间，统一到每1秒。

1. 指出研究对象。
2. 圈出改变的量和保持不变的量。
3. 记录一个现象或一组数据。
4. 立刻说一句：“我看到的证据是……”。

只改变本课研究的一个因素，取得一个清楚现象或一组可比较数据。



安全提示：使用小型、稳定、无尖锐边缘的器材；发现器材异常立即停止。

## 你发现了什么？

现象支持的最短结论是：**速度描述运动快慢**。若证据不足，只写“目前支持”，不要把猜想当结论。

## 10～14分钟｜把现象画出来，建立模型

画：**路程时间条形图**。图上只保留对象、关键方向/变量和边界。

模型句：**单位时间通过的路程**。

## 14～17分钟｜正式物理知识

- 概念：速度描述运动快慢。
- 关系：v=s/t
- 为什么需要：用一个数量关系回答“路程和时间都不同，怎样公平比快慢？”。
- 量与单位：s是路程，常用m；t是对应时间，常用s；v常用m/s。
- 怎样变化：同一路程越短越快；同一时间路程越长越快。
- 适用边界：只用于同一段运动；先统一单位。



## 17～19分钟｜一个典型例题

**题目**：60 m用12 s，速度是多少？

**六步建模**：对象是谁 → 已知什么 → 求什么 → 画最简图 → 选“单位时间通过的路程” → 检查单位和意义。

**答案**：5 m/s，表示每秒通过5 m。

## 19～20分钟｜一句话收束

今天记住：**速度描述运动快慢；单位时间通过的路程。**

## 10分钟练习

1. **概念判断**：用自己的话解释“速度描述运动快慢”。  
   **答案**：必须同时说出物理对象和关系：单位时间通过的路程。只重复标题不算完成。
2. **条件辨认**：写出v=s/t中各量对应的对象，并说一个不能直接使用它的情形。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C6单位错误”。
3. **图示应用**：请画一张“路程时间条形图”，用图解释“单位时间通过的路程”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：60 m用12 s，速度是多少。  
   **答案**：5 m/s，表示每秒通过5 m。关键模型：单位时间通过的路程。
5. **情境与错因侦探**：同学完成“比较两辆玩具车不同路程与时间，统一到每1秒”后出现“C5除法错误”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C5除法错误**。先检查与“单位时间通过的路程”直接相关的对象和条件，再决定重画图、重读数或重算。

## 为什么错

- C5除法错误：回到本课模型卡，重新指出对象和关键条件。
- C6单位错误：只修这一步，再做第4题；不要整课重听。
- 若是C9注意丢失：在题目旁画“对象—条件—单位”三格，完成一格勾一格。
