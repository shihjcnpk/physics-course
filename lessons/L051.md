# 第51课：能量守恒、效率与方向

## 今天只学一件事

回答：**能量守恒，永动机为什么仍不可能？**

## 0～2分钟｜为什么要学它？

先不要找公式。想象这个生活场景：给手机充电能量流贴标签并找散失。本课只追一个变化，不追所有细节。

## 2～5分钟｜先猜一猜

把答案先写成一句话：结果会怎样？你依据的是“看起来”，还是一个可检查的条件？先保留答案，不马上判对错。

## 5～10分钟｜看现象 / 做实验

任务：给手机充电能量流贴标签并找散失。

1. 指出研究对象。
2. 圈出改变的量和保持不变的量。
3. 记录一个现象或一组数据。
4. 立刻说一句：“我看到的证据是……”。

只改变本课研究的一个因素，取得一个清楚现象或一组可比较数据。



安全提示：使用小型、稳定、无尖锐边缘的器材；发现器材异常立即停止。

## 你发现了什么？

现象支持的最短结论是：**能量总量守恒但转化有方向且品质会分散**。若证据不足，只写“目前支持”，不要把猜想当结论。

## 10～14分钟｜把现象画出来，建立模型

画：**能量流桑基简图**。图上只保留对象、关键方向/变量和边界。

模型句：**输入能量=有效+散失**。

## 14～17分钟｜正式物理知识

- 概念：能量总量守恒但转化有方向且品质会分散。
- 关系：E入=E有+E散
- 为什么需要：用一个数量关系回答“能量守恒，永动机为什么仍不可能？”。
- 量与单位：各项都用同一种能量单位。
- 怎样变化：输入固定时散失越少，有效能量越多。
- 适用边界：守恒不等于所有能量都能无条件再次利用。



## 17～19分钟｜一个典型例题

**题目**：输入100 J，有用70 J，散失多少？

**六步建模**：对象是谁 → 已知什么 → 求什么 → 画最简图 → 选“输入能量=有效+散失” → 检查单位和意义。

**答案**：30 J；守恒不等于都能再利用。

## 19～20分钟｜一句话收束

今天记住：**能量总量守恒但转化有方向且品质会分散；输入能量=有效+散失。**

## 10分钟练习

1. **概念判断**：用自己的话解释“能量总量守恒但转化有方向且品质会分散”。  
   **答案**：必须同时说出物理对象和关系：输入能量=有效+散失。只重复标题不算完成。
2. **条件辨认**：写出E入=E有+E散中各量对应的对象，并说一个不能直接使用它的情形。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C7效率超过100%”。
3. **图示应用**：请画一张“能量流桑基简图”，用图解释“输入能量=有效+散失”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：输入100 J，有用70 J，散失多少。  
   **答案**：30 J；守恒不等于都能再利用。关键模型：输入能量=有效+散失。
5. **情境与错因侦探**：同学完成“给手机充电能量流贴标签并找散失”后出现“C1守恒等同不变形式”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C1守恒等同不变形式**。先检查与“输入能量=有效+散失”直接相关的对象和条件，再决定重画图、重读数或重算。

## 为什么错

- C1守恒等同不变形式：回到本课模型卡，重新指出对象和关键条件。
- C7效率超过100%：只修这一步，再做第4题；不要整课重听。
- 若是C9注意丢失：在题目旁画“对象—条件—单位”三格，完成一格勾一格。
