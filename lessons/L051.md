# 第51课：能量守恒、效率与方向

## 今天只学一件事

回答：**能量守恒，永动机为什么仍不可能？**


## 开课前｜数学准备

数学前置：加法、百分数。把加法、百分数用于真实测量、图示或数量关系。

**数学小补丁**：若不稳定，先做5分钟补丁：用一个生活数例复习加法、百分数，只练本课会用到的一步。

## 为什么要学它？

先不要找公式。想象这个生活场景：给手机充电能量流贴标签并找散失。本课只追一个变化，不追所有细节。

## 先猜一猜

把答案先写成一句话：结果会怎样？你依据的是“看起来”，还是一个可检查的条件？先保留答案，不马上判对错。

## 看现象 / 做实验

任务：给手机充电能量流贴标签并找散失。

1. 指出研究对象。
2. 圈出改变的量和保持不变的量。
3. 记录一个现象或一组数据。
4. 立刻说一句：“我看到的证据是……”。

只改变本课研究的一个因素，取得一个清楚现象或一组可比较数据。



安全提示：使用小型、稳定、无尖锐边缘的器材；发现器材异常立即停止。

## 你发现了什么？

现象支持的最短结论是：**能量总量守恒但转化有方向且品质会分散**。若证据不足，只写“目前支持”，不要把猜想当结论。

## 把现象画出来，建立模型

画：**能量流桑基简图**。图上只保留对象、关键方向/变量和边界。

模型句：**输入能量=有效+散失**。

## 正式物理知识

- 概念：能量总量守恒但转化有方向且品质会分散。
- 关系：E入=E有+E散
- 为什么需要：用一个数量关系回答“能量守恒，永动机为什么仍不可能？”。
- 量与单位：各项都用同一种能量单位。
- 怎样变化：输入固定时散失越少，有效能量越多。
- 适用边界：守恒不等于所有能量都能无条件再次利用。



## 一个典型例题

**题目**：输入100 J，有用70 J，散失多少？

**六步建模**：对象是谁 → 已知什么 → 求什么 → 画最简图 → 选“输入能量=有效+散失” → 检查单位和意义。

**答案**：30 J；守恒不等于都能再利用。

## 一句话收束

今天记住：**能量总量守恒但转化有方向且品质会分散；输入能量=有效+散失。**

## 10分钟练习

1. **[基础·北京题型：概念辨析]** 在“给手机充电能量流贴标签并找散失”中，有同学忽略了“C7效率超过100%”。这个结论可靠吗？

   **答案**：不可靠。应先按“输入能量=有效+散失”核对研究对象和条件。
2. **[基础·北京题型：读数/计算]** 输入100 J，有用70 J，散失多少。

   **答案**：30 J；守恒不等于都能再利用。关键条件：对象、过程和单位必须配对。
3. **[典型·北京题型：读图作图]** 围绕“能量流桑基简图”，标出研究对象、关键方向或变量，并用图得出“输入能量=有效+散失”这一结论。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·北京题型：实验探究]** 要完成“给手机充电能量流贴标签并找散失”，写出本次只改变或重点比较的量，以及判断结论所需的证据。

   **答案**：围绕“输入能量=有效+散失”只改变一个关键因素，其他条件保持一致；至少取得可比较的数据或清楚现象，不能由一次偶然结果下结论。
5. **[提升·北京题型：解释/论证]** 把“能量守恒，永动机为什么仍不可能？”改成可检验的问题，并写出需要取得的证据。

   **答案**：先圈定对象和条件，再用“输入能量=有效+散失”连接证据与结论。若出现“C1守恒等同不变形式”，归入 **C1守恒等同不变形式** 并只修对应步骤。

## 为什么错

- C1守恒等同不变形式：回到本课模型卡，重新指出对象和关键条件。
- C7效率超过100%：只修这一步，再做第4题；不要整课重听。
- 若是C9注意丢失：在题目旁画“对象—条件—单位”三格，完成一格勾一格。
