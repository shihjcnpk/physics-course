# 第30课：核心实验：滑动摩擦力受什么影响

## 今天只学一件事

回答：**给箱子加重和铺毛巾，哪种更难拉？**

## 0～2分钟｜为什么要学它？

先不要找公式。想象这个生活场景：只改变压力或粗糙程度，匀速拉木块记录力。本课只追一个变化，不追所有细节。

## 2～5分钟｜先猜并设计

把答案先写成一句话：结果会怎样？你依据的是“看起来”，还是一个可检查的条件？先保留答案，不马上判对错。

## 5～12分钟｜操作与取证

任务：只改变压力或粗糙程度，匀速拉木块记录力。

1. 指出研究对象。
2. 圈出改变的量和保持不变的量。
3. 记录一个现象或一组数据。
4. 立刻说一句：“我看到的证据是……”。

先写自变量、因变量和至少两个控制量；按安全规范完成操作，至少取得三组有效数据。若课堂器材未就绪，使用教师提供的同结构数据做分析，本实验仍需另行完成实操。

### 核心实验设计卡

- 自变量/主动改变：压力或接触面粗糙程度，每次只改一个。
- 因变量/观察测量：水平匀速时的拉力示数。
- 关键控制与规范：速度状态、接触面积处理和其余因素。
- 证据记录：每个条件多次拉力及平均/代表值。
- 结论规则：先描述数据共同趋势，再回答问题；异常数据不许静默删除，要复测或说明。


安全提示：使用小型、稳定、无尖锐边缘的器材；发现器材异常立即停止。 `CORE`实验应在教师或成人指导下完成。

## 你发现了什么？

现象支持的最短结论是：**滑动摩擦与压力和接触面粗糙程度有关**。若证据不足，只写“目前支持”，不要把猜想当结论。

## 12～15分钟｜整理证据，建立模型

画：**水平匀速测摩擦图**。图上只保留对象、关键方向/变量和边界。

模型句：**水平匀速时拉力等于摩擦力**。

## 15～17分钟｜正式物理知识

- 概念：滑动摩擦与压力和接触面粗糙程度有关。
- 关系：F拉=f
- 为什么需要：用一个数量关系回答“给箱子加重和铺毛巾，哪种更难拉？”。
- 量与单位：F拉和f都用N。
- 怎样变化：这里只用读出的拉力间接得到摩擦力。
- 适用边界：仅在物体水平匀速且水平方向只受这两个力时使用。



## 17～19分钟｜一个典型例题

**题目**：研究粗糙程度时什么必须相同？

**六步建模**：对象是谁 → 已知什么 → 求什么 → 画最简图 → 选“水平匀速时拉力等于摩擦力” → 检查单位和意义。

**答案**：压力等条件相同。

## 19～20分钟｜一句话收束

今天记住：**滑动摩擦与压力和接触面粗糙程度有关；水平匀速时拉力等于摩擦力。**

## 10分钟练习

1. **概念判断**：用自己的话解释“滑动摩擦与压力和接触面粗糙程度有关”。  
   **答案**：必须同时说出物理对象和关系：水平匀速时拉力等于摩擦力。只重复标题不算完成。
2. **条件辨认**：写出F拉=f中各量对应的对象，并说一个不能直接使用它的情形。  
   **答案**：对象、过程和状态要配对；本课特别要防止“C4同时改两个变量”。
3. **图示应用**：请画一张“水平匀速测摩擦图”，用图解释“水平匀速时拉力等于摩擦力”。  
   **答案**：至少标出研究对象、关键方向/变量和适用边界；图与文字结论必须一致。
4. **基础应用**：研究粗糙程度时什么必须相同。  
   **答案**：压力等条件相同。关键模型：水平匀速时拉力等于摩擦力。
5. **情境与错因侦探**：同学完成“只改变压力或粗糙程度，匀速拉木块记录力”后出现“C2未利用平衡间接测量”。这属于哪类错误，下一步先检查什么？  
   **答案**：归入 **C2未利用平衡间接测量**。先检查与“水平匀速时拉力等于摩擦力”直接相关的对象和条件，再决定重画图、重读数或重算。

## 为什么错

- C2未利用平衡间接测量：回到本课模型卡，重新指出对象和关键条件。
- C4同时改两个变量：只修这一步，再做第4题；不要整课重听。
- 若是C9注意丢失：在题目旁画“对象—条件—单位”三格，完成一格勾一格。
