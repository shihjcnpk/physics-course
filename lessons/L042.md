# 第42课：功：力什么时候产生了“成果”

## 今天只学一件事

回答：**提着书包水平走，手对书包做机械功吗？**

## 开课前｜数学准备

数学前置：乘法、单位换算。本课数学只服务于物理问题“提着书包水平走，手对书包做机械功吗？”。乘法：由单位量和份数求总量；单位换算：让同类量在计算前使用统一单位。

**数学小补丁**：若不稳定，先做5分钟补丁：用一个生活数例复习乘法、单位换算，只练本课会用到的一步。

## 为什么要学它？

想一想这个生活场景：对比推车前进、提物静止、提物水平走。

## 先猜一猜

把答案先写成一句话：结果会怎样？你依据的是“看起来”，还是一个可检查的条件？先保留答案，不马上判对错。

## 看现象 / 做实验

任务：对比推车前进、提物静止、提物水平走。

1. 指出研究对象。

4. 立刻说一句：“我看到的证据是……”。

只改变本课研究的一个因素，取得一个清楚现象或一组可比较数据。



安全提示：使用小型、稳定、无尖锐边缘的器材；发现器材异常立即停止。

## 你发现了什么？

现象支持的最短结论是：**功需要力且物体沿力方向移动距离**。若证据不足，只写“目前支持”，不要把猜想当结论。

## 把现象画出来，建立模型

画：**力与位移夹向图**。图上只保留对象、关键方向/变量和边界。

模型句：**力与力方向距离的乘积**。

## 正式物理知识

- 概念：功需要力且物体沿力方向移动距离。
- 关系：W=Fs
- 为什么需要：用一个数量关系回答“提着书包水平走，手对书包做机械功吗？”。
- 量与单位：F用N；s是物体在力方向通过的距离，用m；W用J。
- 怎样变化：F或力方向距离增大时功增大。
- 适用边界：只直接用于恒力与运动方向相同的初中模型；有力无位移不做机械功。



## 一个典型例题

**题目**：10 N水平推物前进3 m，做功？

**六步建模**：对象是谁 → 已知什么 → 求什么 → 画最简图 → 选“力与力方向距离的乘积” → 检查单位和意义。

**答案**：30 J。

2. **[基础·读数/计算]** 10 N水平推物前进3 m，做功。

   **答案**：30 J。关键条件：对象、过程和单位必须配对。

   **答案**：图中至少出现对象、方向/变量、条件和结论；箭头、刻度、虚实线必须符合物理意义。
4. **[典型·证据与实验]** 把例题信息整理成“对象—条件—关系—结论”四格，不增加题目没有给出的条件。

   **答案**：对象和条件必须来自题目；关系使用“力与力方向距离的乘积”；最后用单位或物理意义检查结论。
5. **[提升·解释论证]** 把下面的核心问题改成可检验的问题，并写出需要取得的证据：提着书包水平走，手对书包做机械功吗？

## 为什么错

- **漏力方向**：重读题目，只圈出决定答案的条件，再作答。
- **有力就判做功**：写出这个关系的适用条件，再判断本题能否使用。
- **做题中途漏条件**：在题目旁画“对象—条件—单位”三格，完成一格勾一格。
